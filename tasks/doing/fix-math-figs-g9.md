# Рисунки там, де задача їх вимагає: g9

Звернення вчителя: у частині задач умова посилається на рисунок або без нього незрозуміла (геометрія з позначеннями, яких немає на екрані; графіки; координатна площина; діаграми), а рисунка немає. Кандидатів знайшов `node tools/fig-audit.mjs` (reports/fig-audit-math.md, евристики — `figCues` у tools/lib.mjs). Евристика дає й хибні збіги — **рішення по кожному пункту за тобою**.

## Що зробити
Для кожного кандидата нижче — одне з трьох:
1. **Рисунок потрібен** (без нього не зрозуміло, де які точки/ребра/відрізки; умова каже «на рисунку»; дані треба прочитати з графіка/діаграми) → додай ілюстрацію на цей екран чи вправу:
   - геометрія на площині — статичний `lab: { kind: "plane", axes: false, view: [...], points, segs, polys, angles, circles, texts }` без `params` (зразки: g7-g7m4.js, g8-g8m2.js — пошук `axes: false`); тіла — `lab: { kind: "solid", shape: "box"|"prism"|"pyramid", marks }`; діаграми — `lab: { kind: "chart" }`; графік функції — `lab: { kind: "plane", fns: [...] }` (CONTENT_SCHEMA §8). `fig` (§6) — лише дробові фігури. На екрані одна ілюстрація (fig | img | svg | lab).
   - **Точність = умова:** позначення точок ті самі, що в умові, розміри/кути в пропорції до даних (трикутник 3–4–5 — саме такий), прямий кут — прямий, паралельні — паралельні. Підписи — лише дані умови. **Рисунок не підказує відповіді** (D-019, чесне завдання): не підписуй шукану величину й не роби її вимірюваною з сітки, якщо задача про обчислення. Підписи SVG — безпечна підмножина TeX (CONTENT_SCHEMA §8.1). `lab.alt` — простий текст без $.
2. **Рисунок не потрібен** (задача зрозуміла словами: «у трикутнику ABC кут A = 50°, B = 60°, знайди C»; «побудуй графік»; «точка лежить на графіку функції») → нічого не міняй, один рядок у нотатках: id — чому.
3. **Посилання на рисунок, який точно намалювати не вдається** (немає даних, рисунок з підручника) → перепиши умову так, щоб вона була зрозуміла без рисунка (не змінюючи ключа), або, якщо й це неможливо, — запиши в нотатки «не вдалося точно: …» для людини.

Правила: id екранів/вправ не змінюй; ключі відповідей не змінюй (якщо знайшов помилку ключа — нотатки + inbox). Змінений урок/пул/тест → `status: "draft"` лише для зачеплених уроків (пул/тест — увесь файл), як у fix-math-content-minor-1101. Свій файл — лише файли зі списку `files`. **build не запускай** (оркестратор). Перевір: `node tools/validate.mjs --section <id> | --pool <id> | --diag <id>` — 0 помилок і жодного попередження «умова посилається на рисунок» у твоїх файлах; `node tools/fig-audit.mjs` — перелічи, що лишилося в твоїх файлах і чому. Для змінених уроків — `python3 tools/playtest.py --section <id>` (build не потрібен: index.html підвантажує твій файл як є; браузерні тести під паралельним навантаженням флейкають — повтори один раз). Подивись на рисунок у браузері (`playtest.py --shots` або власний скрипт Playwright, Chromium `/opt/pw-browsers/chromium`) — знімки в `<scratchpad>/fix-math-figs-g9/`.
