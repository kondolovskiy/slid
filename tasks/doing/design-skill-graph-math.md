# Skill Graph (пріоритет 2): формальні залежності поверх sk і pre, спершу математика

Розширити чинні `sk` і `pre`/prerequisites (матриця v3) формальними залежностями між навичками й уроками; не змінювати наявних id навичок і уроків. Для історії — та сама архітектура з типами навичок: хронологія, аналіз джерел, причинно-наслідкові зв'язки, аргументація (окрема задача куратора). Дизайн-документ, валідатор графа (цикли, сироти), незалежне рев'ю.
