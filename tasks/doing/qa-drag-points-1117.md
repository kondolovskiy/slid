## Що зробити
1. Реальні пристрої: телефон (Android Chrome, iOS Safari, 360–390 px) і ноутбук з мишею/тачпадом. На кожному — по 2–3 екрани з таблиці: перетягнути точку; тапнути поруч із точкою; перевірити, чи досяжна потрібна позиція (крок `step`/snap).
2. Клавіатура: порядок Tab (чи точка досяжна без зайвих зупинок), видимий фокус.
3. Для кожного пункту — висновок: працює / баг рушія / баг змісту (наприклад, «мертва» ручка, крок не дозволяє точне значення).
4. Пропозиції (для engine-задачі, якщо підтвердиться): тап по сітці переносить точку; клік по точці фокусує її; видима підказка «тягни або стрілки»; повзунок-дубль для точок на осі.
