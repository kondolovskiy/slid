## Варіанти для документа (не вичерпно)
1. Рівні: шкала на рік класу (поріг ≈ від кількості уроків класу × середній XP) або нескінченні рівні з назвами-етапами; нейтральні назви (іменники без роду: «Новачок» → «Старт», «Дослідження»… — або «рівень 5»), узгодити з D-020a (значки не перейменовуємо — id прогресу).
2. Денна ціль: 1 урок / N хв / вибір учнем; відображення лінії цілі в масштабі.
3. Значки: показувати лише класу учня (+ «інші класи» згорнуто), отримані — першими й виділені текстом.
4. Навички: зараховувати й уроки (журнал подій, docs/EVIDENCE.md) — узгодити з персоналізацією (docs/PERSONALIZATION.md, SRS).
5. Повторення: менше XP за повтор або варіант завдань із пулу (див. engine-diag-retest-from-pool, D-050 п. 1).
6. Міграція збереженого стану `slid.v1` (рівень дитини не повинен «впасти» несподівано).
