3. **Джерела — реальні вправи:** базовий підручник З8 (facts/ukr.md «Джерела»: бібліографія, URL, відповідність сторінок PDF) — номер вправи в `src` («З8 впр. 123(2)»), сторінка; додаткові — інші рекомендовані МОН підручники чи збірники з URL. 4. **Типи:** переважно мовні вправи, де дитина пише чи позначає сама — `gaps` (вставити букву чи розділовий знак), `stress`, `pick` (знайти в реченні), `word`, `split`; `sort` / `order` — для класифікацій; `choice` / `multi` — лише для поняттєвих питань («чому так пишемо»), не замість правопису.
5. Кожна вправа: сталий `id`, `lesson` з переліку, `sk` (з `sk` екранів уроку), `lvl`, пояснення-розбір (правило + чому саме так), `hint` для рівнів 2–3.
6. **Норма (D-041, D-042):** помилкою — лише ненормативне і за підручником чи УП, і за словником (СУМ, ОС, ВЕСУМ / Горох); вибір між нормативними варіантами (у/в, і/й, із/зі перед збігом) не оцінювати; наголос — за словником, звіряти за зображенням сторінки (у PDF З7 наголоси губляться). Кожну вправу розв'язати двічі.
7. Милозвучність і стиль — style/ukr.md, `node tools/euphony.mjs --subject ukr` (лише stdout для свого файлу).
