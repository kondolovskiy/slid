## Прогалини покриття (рішення — людина / оркестратор)
1. **cur-проб немає** для жодного з 18 уроків (політика — одна cur-тема на розділ; для g9m8 cur-теми немає взагалі — розділ новий). Як у v7/v8 (рішення 04.11 для dg5–dg8: нових cur-проб не додаємо — нове завдання = новий id тесту): чи лишити так і для dg9, зокрема для цілого розділу g9m8?
2. **Розділ g9m8 без жодної pre-теми.** Опори: ms4l2 (паралелепіпед і куб, 6 кл.) — g9m8l1, l5, l6; g8m4l2 (теорема Піфагора) — g9m8l2, l3, l5, l7, l10; g7m6l1 (ознаки паралельності) — g9m8l2; g9m6l2 (коло і круг) — g9m8l9, l11. 3. **Опори поза `for` свого розділу** (варіант — розширити `for`, без нових завдань і `rev`, як у v8):

   - g9m3l7 (задачі системами) ← g8m4l2 — тема `pyth` має `for` g9m2, g9m4, не g9m3.
   - g9m4l5 (площа через синус) ← g8m6l1 (многокутники) — тема `polygon` має `for` лише g9m6.
   - Решта опор — у тому самому розділі (g9m4l6 ← g9m4l5, g9m5l5 ← g9m5l3, g9m6l6 ← g9m6l1/l2, g9m6l7 ← g9m6l4/l2) або вже в `for` свого розділу (g9m3l6 ← g8m5l2 — `quad`).
