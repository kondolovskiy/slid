4. **Типи:** переважно мовні вправи, де дитина пише чи позначає сама — `gaps` (вставити букву чи розділовий знак), `stress`, `pick` (знайти в реченні), `word`, `split`; `sort` / `order` — для класифікацій; `choice` / `multi` — лише для поняттєвих питань («чому так пишемо»), не замість правопису.

Кожну вправу розв'язати двічі.
