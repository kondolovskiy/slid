## Що розглянути

- Кінцевий нуль при округленні: «округли до десятих» → вимагати «37,0» замість «37» (прапорець на кшталт `decimals: 1`), сумісність із `tol`.

## Рішення (2026-10-31; людина доручила оркестратору — «знайти рішення, що відповідає цілям»)
Мета: дитина не втрачає спробу через спосіб запису, а не через математику; нові поля — опційні, старі ключі поводяться так само.
1. **`answerKind: "time"`**: ключ `"9:55"` (24-год). Приймати «9:55», «09:55», «9.55», «9 год 55 хв», «9 год. 55 хв.»; хвилини 00–59 обов'язково двозначні після «:»/«.»; «955», «9:5» → bad з поясненням формату. Клавіша «:» у полі.
2. **Складені величини `answerKind: "quantity"`**: ключ — число в найменшій одиниці + `units` з таблиці (довжина мм/см/дм/м/км, маса г/кг/ц/т, час с/хв/год/доба, гроші коп/грн). Приймати будь-який рівний запис («2 м 45 см», «245 см», «2,45 м»); `form: "compound"` вимагає саме складеного запису у великих одиницях без дробів (інакше form-підказка). Чужа фізична величина → bad «Перевір одиницю».
3. **`form: "improper"`** — лише неправильний дріб: мішане число того самого значення → form «Запиши неправильним дробом».
4. **`decimals: n`** для number: значення, рівне ключу, але з іншою кількістю знаків після коми («37» при decimals 1) → form «Запиши з n знаком(ами) після коми»; сумісно з `tol` (tol перевіряє значення, decimals — запис).
5. **Префікси, що не змінюють відповідь:** `x = 5` / `b = 1` у number; `AB = (…)`, `AB(…)`, `\vec{AB} = (…)` у coordinates2/3 (1–2 великі латинські літери); будь-який `<вираз> ∈` перед intervalSet. Мала літера перед дужками в символьному coordinates2 — **не** назва точки (множник), числовий шлях — без змін.
6. **Періодичний дріб** `-0,(3)` у number/exactRoot, коли ключ раціональний: приймати як рівний.
7. **Одиниці**: крапка після одиниці («60 грн.»), «º» як «°», «разів/раз/рази» для unit «раз»; «Перевір одиницю» — лише якщо число без одиниці правильне.
8. **list із повторами:** `multiset: true` у ключі list — порівняння мультимножин.
Дефолти: усе нове вмикається лише явним полем у ключі (крім п. 5–7, що безпечно розширюють прийняття однозначних записів). Перед злиттям — диференційна регресія на всіх verified пулах і діагностиках 4–9: розбіжності лише з п. 5–7, кожна задокументована.
