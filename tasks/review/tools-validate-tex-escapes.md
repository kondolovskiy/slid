# validate: ловити TeX-команди з одним бекслешем у JS-рядках

Знахідка верифікатора pg9m2: у g9-g9m2.js `"$|\Delta x|$"` і `"\overrightarrow{AB}"` у звичайних лапках — JS ковтає `\D`/`\o`, учень бачить «Delta x». Виправлено оркестратором (рядки 74, 76, 78, 482). Валідатор цього не ловить.
- Після завантаження контенту шукати в рядках екранів/пулів/діагностик залишки назв команд з app/math.js COMMANDS без `\` усередині `$…$` (напр. `Delta`, `overrightarrow`, `frac`, `sqrt` перед `{`), або сканувати сирий JS-текст на `\<літера>` поза валідними escape.
- Помилка (не попередження). Регресійні тести. Незалежне рев'ю (D-026).

## Нотатки виконавця
Виконавець: agent-tools-validate-tex-escapes (worktree wt-tex3, 2026-11-01), спільне рев'ю з engine-render-tex-p3.
- Обрано скан **сирого** тексту файлів змісту (`jsEscapeIssues` у tools/validate.mjs): після завантаження `"\frac"` уже став `\f`+«rac», а `"\Delta"` — «Delta», і відрізнити це від звичайного слова надійно не можна. У кожному літералі `"…"`, `'…'`, `` `…` `` (коментарі пропускаються) шукається непарна кількість `\` перед латинськими літерами. **Помилка**, якщо escape не існує в JS (`\D`, `\o`, `\s`… — JS ковтає `\`) або це валідний escape `\b \f \n \r \t \v`, за яким іде назва TeX-команди (MATH_COMMANDS + theta, beta, nu, tau, right, rangle, binom, varphi…: `\frac`, `\neq`, `\vec`, `\times`, `\to`, `\begin`, `\right`). `\n` перед кирилицею, `\u00e9`, `\\Delta` — чисто.
- Повідомлення: `content/math/g9-g9m2.js:57: «\Delta» з одним бекслешем у JS-рядку — JavaScript ковтає «\», учень побачить «Delta»; пиши «\\Delta»`. З `--section` — файл розділу (origin, інакше файл з `id: "<id>"`), з `--diag/--pool` — файл з цим id.
- На чинному змісті (усі предмети, усі файли content/): **0** випадків. Перевірено: у копії дерева повернув баг g9m2 (р. 57, 61 з одним `\`) → 2 помилки з номерами рядків.
- Регресія: test-validate, 8 випадків ESC (4 види лапок/escape, 3 негативні, `\\\Delta`) + повний прогін. Мутації validate: вимкнути скан — 13 падінь; без гілки «керівний символ + команда» — 6; без перевірки парності `\` — 16; сканувати коментарі — 10.
