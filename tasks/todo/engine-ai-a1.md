## Рішення людини (2026-11-02, чат) на §9 дизайну
1. Хто платить: **школа або грант/партнер** — «шукаємо варіанти»; проєкт не платить за замовчуванням. До рішення — місячна стеля бюджету в конфігу сервера, без неї функція не вмикається.
2. Згода на фото: **(а)** — лише шкільні акаунти, школа підписує угоду про обробку даних (наш сервер, Anthropic у США), вмикає для домену; «подивимось» далі. Типово — **вимкнено** (рекомендація дизайну; людина не заперечила).
3. «Дорослий»: **(в)** — розділ «Для дорослого» на пристрої зараз, кабінет учителя згодом.
4. Фото на сервері: **(а) + (г)** — видаляти одразу після вердикту (на телефоні ще 7 днів для оскарження); довше лише для еталонного набору за окремим дозволом.
5. Людина в циклі: **(б)** — спершу 2–3 тижні вердикт бачить лише дорослий (≥ 30 реальних розв'язань), потім дітям. Граф у тіні не оновлювати (рекомендація; людина окремо не відповіла).
6. Правильна відповідь + хибний хід: **(а)** — не помилка для повторень, лише повідомлення й граф знань.
7. Модель: **(б)** найдешевша, що пройде поріг, **і закласти можливість тестувати кілька моделей** — `tools/ai-eval.mjs` приймає список рівнів/моделей із конфігу (без id у репозиторії), порівняльний звіт; на сервері — модель зі змінної середовища, перемикання без зміни коду.
8. Тривожний вміст: **(б)** — ШІ лише позначає, бачить відповідальна особа школи за її протоколом (поле `concern` — після погодження протоколу зі школою).
9. Вердикт дитині: **(а)** — лише після всіх спроб.
