# «Перевір одиницю» замість «Зміни відповідь», коли величина правильна в іншій одиниці
З рев'ю reports/review/engine-answer-unit-choice.md (P2, рушій). Для `answer` з `unit` (не quantity): коли запис дитини — та сама величина в іншій одиниці (напр. «2000 г» при ключі 2 кг), зараз `badHint` пише «Зміни відповідь» і вводить в оману. Показувати наявне `unitMsg` («Перевір одиницю: тут відповідь записують у «кг»») — воно не стверджує, що значення правильне, тож безпечне й для задач на переведення. **Вердикт лишається bad**, нового парсера не треба.
- Тінь гіпотез: такий запис не має відкривати «обчислення/поняття» як звичайна помилка — або нова причина `form`/`fc` (тоді перевір правило rv §3.3), або явно задокументуй, як трекер його бачить.
- Тести: test-learn (719/651 проб рецензента — текст підказки), diff-answers (нова категорія для зміни тексту підказки, вердикти 0 змін), регресія в браузері.
