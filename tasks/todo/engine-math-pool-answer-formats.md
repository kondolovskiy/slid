# Закрити формати відповідей, потрібні пулам 7–11 класів

## Межі

Це єдиний виконавець форматів із початкового пункту 3 engine-practice-pool; у залишковій задачі лишено лише вибір одиниці. Не реалізовувати генератори чи автоматизацію створення задач. comparison/list/factors, fractionOnly, tol, srcPage/adapted/unitForms уже реалізовані в engine-diag-pool-answers. Не реалізовувати їх повторно. Звичайний list не означає впорядковану пару координат.

## Що зробити

1. За матрицею зафіксувати конкретні вправи, які не виражаються чинним answer: відношення, впорядкована пара/трійка координат, точна відповідь із коренем/π, проміжок або множина розв’язків, еквівалентний вираз. Визначити мінімальну потрібну підтримку, не загальну систему комп’ютерної алгебри.
2. Для кожного потрібного формату описати контракт, припустимі еквіваленти, порядок, роздільники, область визначення, округлення й приклади правильних/неправильних записів. Підтримати в checkAns, validatePool та UI answer разом; без eval учнівського вводу.
3. Два корені без порядку можна подати чинним list; для впорядкованих координат потрібна окрема семантика. Якщо потрібного формату немає, не підміняти перевірюване вміння запитанням про кількість відповідей чи десятковим наближенням без дозволу умови.
4. Поняттєві питання choice/multi допустимі за схемою, але ними не замінювати всі вправи зі самостійним записом відповіді. Доведення не оголошувати автоматично перевіреним за одним числом.
5. Документувати §10; узгодити з engine-practice-pool виконаний підскоуп. Генератори, випадковий добір діагностики з пулу та AI-перевірка ходу не входять у цю задачу.
