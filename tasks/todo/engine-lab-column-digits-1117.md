# Стовпчик і ділення кутом: цифри відповіді не вписати — фокус не переходить між клітинками, лише «+1» за дотик

Скіл `engine-change`. Незалежне рев'ю D-026.

## Проблема
Лабораторія `kind: "column"` з `input: true` (app/lab.js: цифри `d0, d1…` як приховані параметри ≈ рядок 149–166, 634; дотик по цифрі — `h.tap` ≈ 817; клавіатура — `svg keydown` ≈ 822 і `handleTargets` ≈ 846, у колах `pointer-events="none"`):
- дотик по клітинці не ставить на неї фокус і не відкриває клавіатуру, а лише додає +1 по колу («?» → 0 → … → 9): до 10 дотиків на цифру;
- після фокусу на першій клітинці цифри з клавіатури потрапляють лише в неї; дотик по 2-й, 3-й клітинці фокус не переносить — «1524» стає «4000»;
- «Перевірити» активна при порожніх клітинках «????», порожня відповідь зараховується як помилка;
- текст екранів обіцяє «вписуй цифри», а вписати не можна.

## Що зробити
1. Дотик/клік по клітинці → фокус на ній (і, де можливо, числова клавіатура: прихований `<input inputmode="numeric">` над SVG або HTML-клітинки замість SVG-кіл); «+1 за дотик» прибрати або лишити лише як другий спосіб (кнопки ▲▼).
2. Введення цифри → значення в цій клітинці і автоперехід до наступної (порядок: для суми/різниці — справа наліво, для ділення кутом — зліва направо); Backspace — стерти й назад.
3. «Перевірити» неактивна, доки є «?» (або порожня відповідь не рахується спробою).
4. Видимий фокус клітинки; підказка в тексті екрана відповідає способу вводу.
5. Крапки позики й знак множення — читабельні на 360 px.
