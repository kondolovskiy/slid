# Тренування: що лишилося після першої версії

## Зроблено (2026-10-13)
Рушій тренування (docs/PERSONALIZATION.md §3, CONTENT_SCHEMA §10): `SLID.pool`, тип `answer`, добір сесії, коробки Лейтнера, екран «Тренування», пули для математики 6 класу (g6m1–g6m5) з реальних підручників.

## Що лишилося
1. **Генератори** (`gen`) на виразах лабораторії: змінні з діапазонами, умова `where`, обчислювана відповідь — щоб обчислювальні задачі не закінчувались (для рівня 1).
2. **Пули для інших класів:** `tools/make-tasks.mjs` — тип `write-pool` за зразком `tasks/done/write-math-pool-g6m*.md`; спершу 5 клас (на нього веде план 6-класників).
3. **Відповіді, яких схема ще не вміє:** відношення `2 : 3`, два корені, координати точки, вираз (`3a + 5`), одиниці на вибір.
4. **`tools/playtest.py`:** прохід сесії тренування (зараз перевірено вручну в браузері); тип `answer` уже підтримано.
5. **Тест рівня з пулу:** добирати завдання діагностики з пулів, щоб повторне проходження не повторювало ті самі задачі.
6. **Початкові коробки з тесту рівня:** `ok` → 3-тя коробка, `shaky` → 1-ша.
7. Суміжне: ШІ-перевірка ходу розв'язання — окрема задача `engine-ai-solution-check`.

## Відкриті питання до Віктора
- Досвід за тренування зараз як в уроці (10/5 за задачу, без бонусу за урок) — лишити чи зменшити, щоб не «фармили» легкі теми?
- Чи показувати розклад («повернемося через 3 дні») — зараз показуємо наприкінці сесії.
- Історія: пул із фактів ризикує стати зубрінням — можливо, лише завдання на джерела й хронологію.
