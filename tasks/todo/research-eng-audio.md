# Аудіо для англійської: голоси TTS на пристроях учнів, ліцензії голосів, формат файлів

## Навіщо
Рішення людини щодо аудіо (docs/design/english.md §5.3, §11 п. 7) потребує даних. Код не пишемо.

## Що з'ясувати
1. Які англійські голоси `speechSynthesis.getVoices()` дає без мережі на типових пристроях учнів: Android Chrome (з мовним пакетом і без), iOS Safari, Windows Chrome/Edge, ChromeOS. Сторінка-проба (лише в scratchpad, не в репозиторії) або дані з документації браузерів. Локальний (`localService`) чи мережевий.
2. Синтез для файлів: які голоси мають ліцензію, що дозволяє освітнє використання й поширення аудіо (перевірити текст ліцензії кожного голосу); запис учителем — що потрібно (згода, ліцензія CC BY чи передача прав).
3. Формат: AAC (.m4a) / MP3 / Opus — підтримка в Safari iOS 15+, Chrome Android; бітрейт для мови (24–48 кбіт/с) і розмір.
4. Оцінка обсягу для 5 кл. (≈ 60 уроків).
