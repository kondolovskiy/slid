1. Прочитай уроки розділу повністю: що саме пояснено, які приклади й винятки, `sk` екранів, `learned`. **Чесне завдання (D-019):** вправа тренує лише те, що урок пояснив; нового правила пул не вчить.
2. На кожен урок — **4–6 вправ**: ~2 рівня 1 (одне правило, типовий випадок), 2 рівня 2 (кілька слів чи випадків, змішані з уже вивченим), 1–2 рівня 3 (виняток, складний випадок, пастка з уроку). Разом ≈ 20–30 вправ.
3. **Джерела — реальні вправи:** базовий підручник З7 (facts/ukr.md «Джерела»: бібліографія, URL, відповідність сторінок PDF) — номер вправи в `src` («З7 впр. 123(2)»), сторінка; додаткові — інші рекомендовані МОН підручники чи збірники з URL. Не вигадувати джерел і номерів; речення можна скоротити (`adapted`), зберігаючи орфограму. Літературні цитати — з автором.
4. **Типи:** переважно мовні вправи, де дитина пише чи позначає сама — `gaps` (вставити букву чи розділовий знак), `stress`, `pick` (знайти в реченні), `word`, `split`; `sort` / `order` — для класифікацій; `choice` / `multi` — лише для поняттєвих питань («чому так пишемо»), не замість правопису.
5. Кожна вправа: сталий `id`, `lesson` з переліку, `sk` (з `sk` екранів уроку), `lvl`, пояснення-розбір (правило + чому саме так), `hint` для рівнів 2–3.
