# Мовні вправи в тесті рівня (gaps, pick, stress, word, split)

## Навіщо
Запит людини (2026-11-06): тести рівня з української мови (`write-ukr-diag-g5`, `-g6`, `-g7`). Уроки ukr перевіряють уміння мовними вправами (`app/lang.js`, CONTENT_SCHEMA §4.1): наголос, пропуск букви, пошук слова в реченні, поділ на склади й морфеми. Зараз тест рівня їх не дозволяє — `SLID_LEARN.DIAG_TYPES` (app/learn.js:13) = choice, multi, sort, order, number, fracin, shade, numline, lab, answer. Без мовних типів тест з наголосу чи правопису довелося б будувати на `choice`, а це інше вміння: дитина впізнає правильне написання серед готових, а не пише сама.

**Плеєр, найімовірніше, уже готовий:** у тесті рівня неанотоване завдання оцінюється `gradeNow(s) ? OK : BAD` без фідбеку (app/app.js, `check()` при `run.diag`). Перевір це, а не покладайся.

## Що зробити (скіл `engine-change`, TDD)
1. **Допуск:** `gaps`, `pick`, `stress`, `word`, `split` — у `DIAG_TYPES`. Один перелік (validate бере його з learn.js) — без копії.
2. **Вердикт без фідбеку:** правильно все → OK, інакше BAD (часткового зарахування немає; `gaps` з кількома пропусками — усі мають бути правильні). Після «Перевірити» в тесті — жодного позначення зеленим/червоним, жодного показу правильної відповіді, другої спроби немає (як для інших типів). «Ще не знаю» працює. Перевір і `word` з `keys`, і `split` із `zero`.
3. **Обмеження валідатора для тесту рівня** (одне завдання = одне вміння, дитина не вгадує):
   - `gaps` — ≤ 3 пропуски; `stress` — ≤ 3 слова; `pick` — ≤ 20 слів і ≤ 3 правильні; `split` — одне слово (масив — лише варіанти поділу того самого слова, як в уроці);
   - `hyp` у тесті й надалі заборонено;
   - поля фідбеку (`fbOk`, `fbText`, `hint`) у тесті не потрібні — як для інших типів (попередження, якщо є: дитина їх не побачить).
   Межі — пропозиція виконавця; якщо вважаєш інші розумнішими, обґрунтуй у нотатках.
4. **Журнал подій** (docs/EVIDENCE.md): подія `answer` для мовних типів у тесті — з `raw` (стан вправи) і `res`, як в уроці.
5. **Тести:** test-learn (validate: допуск, межі, `hyp`), браузерний сценарій (tools/test-ui.mjs — локально є Node Playwright; або test-answer-ui.py — лише в CI): тест рівня ukr-фікстури з `gaps`, `stress`, `pick`, `word`, `split` — без позначень після відповіді, вердикти OK/BAD у `S.diagRun`, «Ще не знаю», продовження після перезавантаження. Мутант «позначення в тесті» має падати.
6. **Документація:** CONTENT_SCHEMA §9 (перелік типів, межі, приклади мовних завдань); AGENTS.md §6 — тест рівня ukr: скіл `math-pool-diag` (розділ «Тест рівня») + `content-author` (стиль і норми ukr) або окремий розділ «Тест рівня ukr» у `.claude/skills/math-pool-diag/SKILL.md` (джерела З5–З7, D-041/D-042, glossary/ukr). Правка `.claude/` — теж через рев'ю.
