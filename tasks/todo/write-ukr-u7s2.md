# Написати розділ «Орфографічний практикум» (Українська мова, 7 клас)

## Навіщо (з плану, можна уточнити)

3. Подвоєні букви
4. Складні слова разом і з дефісом. Зміни приголосних перед -ськ-, -ств-

6. Фінальний урок розділу (boss: true, бали ×2, свій значок у sec.badges)

Номери відмін і дієвідмін — латиницею I, II, III, IV.
