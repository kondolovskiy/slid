# Формати відповіді з пакета пулів D-043 (рядки ENGINE в inbox 04.11)

1. `list` з числовим ключем-масивом (`[-3, 3]`) приймає запис «±3» (зараз лише ключ-рядок з «±»).
2. Новий answerKind / форма «стандартний вигляд числа» ($a·10^n$, $1 ≤ a < 10$): правильне значення в іншому записі → `form` (підказка), а не `ok`; хибне → `bad`.
3. Новий answerKind «множина пар» (розв'язки систем: «(3; 2), (-2; -3)», порядок пар довільний, порядок у парі — суттєвий).
4. Відповідь у вигляді відношення «1 : 4» при ключі-дробі `1/4` → `form` з підказкою (не мовчазне `bad`).
Не змінювати поведінку для наявних ключів (регресія: test-math, test-learn, test-answer-ui --suite regression і --suite content для всіх пулів math).
