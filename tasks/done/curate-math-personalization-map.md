4б. Куратор у межах цієї задачі оновлює переліки й критерії залежних авторських та перевірочних задач: указує required/optional/pending біля конкретних уроків, перераховує обов’язкову кількість вправ і покриття. Не змінювати сталі id й не видаляти задачі мовчки. Для розділу без required-уроків позначити задачу відкладеною в нотатках; done не ставити без результату. Нові загальні навички додає куратор цієї матриці, не автори файлів. Якщо матриця виявила нову потрібну правку dg6/pg6, створити окрему наступну задачу з незалежною перевіркою; внести її до залежностей verify/qa 6-го класу, якщо вона потрібна для його обов’язкового покриття.
