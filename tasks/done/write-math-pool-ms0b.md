### Сумнівні місця (для verify-math-personalization-g5)
- **Опора на властивість «частина + частина = ціле»** (відрізки a02–a05, a07, a08; кути b04, b05, b07, b08). Урок ms0bl1 не формулює $AB = AC + CB$; урок ms0bl2 — лише для розгорнутого кута (екран 9 «Розгорнутий кут поділили»). Для рівня 1 властивість дописана в умову; для рівнів 2–3 — у hint. Матриця (dg7 `lines`: «Знайти довжину частини відрізка» → ms0bl1) таку пробу вважає належною цьому уроку.
- **b06 (4 год → 120°):** урок дає лише 3:00 = 90° (екран 3); 30° на проміжок виводиться з цього в hint (90 : 3).
- **a01:** «один відрізок між двома точками» урок прямо не каже; опора — «через дві точки лише одна пряма» (екран 2/4).
- **a08 (list):** випадок «A між B і C» вимагає накреслити обидва варіанти; hint підказує обидва.
- **sk:** матриця для ms0bl4 рекомендує `geom`, а урок ms0bl4 і dg6 (тема geom) мають `meas`. Щоб QA не позначав «немає навички матриці geom», d05 (п'ятикутник) — `geom`, решта ms0bl4 — `meas`. Варто вирішити куратору: або sk матриці для ms0bl4 → `meas`, або всі задачі → `geom`.
- **Формати понад матрицю:** list у ms0bl1/ms0bl2 і multi у ms0bl2 (матриця для l2 — лише number). Це реальні «знайди всі»/«які з кутів» з підручника; QA не скаржиться.
