### Факти (з джерелами)
1. Паралельні прямі на площині — не перетинаються; $a\parallel b$; січна перетинає обидві. — miyklas https://www.miyklas.com.ua/p/geometria/7-klas/vzayemne-rozmishchennia-priamikh-na-ploshchini-13636/paralelni-priami-13637/re-0d28c537-fea9-402c-b4e8-3feac0bd34f3 ; Мерзляк Геометрія 7 §3
2. Аксіома паралельних (Евкліда): через точку поза прямою — лише одна паралельна даній. — те саме miyklas; Мерзляк
3. Ознаки: відповідні рівні; внутрішні різносторонні рівні; сума внутрішніх односторонніх = 180°. — miyklas; Новатіка https://novatika.org/uk/7-klas-geometriya-uroky/vzayemne-rozmishhennya-pryamyh/prezentacziya-oznaky-paralelnosti-pryamyh-geometriya-7-klas-nush/
4. Властивості (обернені): при $a\parallel b$ ті самі рівності/сума 180°. — miyklas; Новатіка властивості кутів
5. Дві прямі ⊥ до третьої ⇒ паралельні (наслідок). — згадано в l2 фіналі через січну під 90°.
