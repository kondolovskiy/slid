## Що зробити
1. Де значення не існує — показувати «не існує» / «не визначено» (через умову в шаблоні або межі параметра, що оминають заборонену точку), а не «∞»; точки з x = 0 / x = 2 не малювати.
2. Межі: k ≠ 0, a ≠ 1 (пропустити 1 або пояснити «основа 1 — недопустима»), білих ≥ 0, m ≤ n (`max: "n"`, якщо рушій підтримує, інакше — пояснення в моделі), x < 0 для √x (або прибрати «Спробуй від'ємне x»).
3. `view`/масштаб у g10m1l3: однаковий крок осей, усі точки в полі.
4. Кроки повзунка t у g10m5l2 — частки π (рушій має `|pi`), щоб sin t = sin(t + 2π) було видно.
5. Округлення: різниця кутів через ті самі округлені значення (або цілі кути), суми частин — так, щоб сходились (100 %), однакова база для «середнього» на діаграмі й у тексті.
6. Діагональ коробки: показати відрізок і його довжину; додати d² = a² + b² + c² у шпаргалку.
