### Факти / конвенції (усе — шкільні правила, без історичних фактів)
- Десятковий дріб — запис дробу зі знаменником 10, 100, 1000… через кому; читання через «цілих / десятих / сотих / тисячних»; множення на 10, 100 — кома праворуч, ділення — ліворуч; у добутку після коми стільки цифр, скільки в обох множниках разом; порівняння — розряд за розрядом, починаючи з цілої частини — https://novatika.org/uk/5-klas-nush/desyatkovi-droby-uk ; https://naurok.com.ua/zanyattya-z-distanciynogo-kursu-okruglennya-desyatkovih-drobiv-194711.html
- Правило округлення: перша відкинута цифра 0–4 — остання цифра не змінюється; 5–9 — збільшується на 1 (те саме формулювання, що в ms0 для натуральних) — https://naurok.com.ua/zanyattya-z-distanciynogo-kursu-okruglennya-desyatkovih-drobiv-194711.html
- 1 м = 100 см (реєстр, №1); 1 грн = 100 коп. (шкільна конвенція).
- Середнє арифметичне = сума : кількість чисел (стандартне означення).
- Усі числа в задачах (ціни, маси, кроки, час забігу 10,2/9,8/10,0 с) — вигадані сюжетні дані, не рекорди й не реальні ціни.
