Норми (джерела):
- Відокремлення — виділення члена речення для посилення смислового значення; на письмі — коми, зрідка тире; усно — інтонація; відокремлюються означення, додатки, обставини — З8 с. 190 https://file.4book.org/images/shcoolbook_ua/8/8_um_z_2025.pdf
- Узгоджене означення відокремлюємо: при особовому займеннику; відділене іншими членами речення; зворот / прикметник із залежними словами після означуваного; два й більше одиничних після слова, перед яким уже є означення; з обставинним відтінком причини чи умови; зворот перед словом без відтінку — не відокремлюємо — З8 с. 190–191; друге джерело https://uk.wikipedia.org/wiki/Відокремлені_члени_речення
- Одиничні узгоджені після іменника без попереднього означення — «можна відокремлювати або не відокремлювати» (за бажанням автора); тире при експресивному означенні — З8 с. 196.
- Неузгоджені: іменник у непрямому відмінку — коми або тире; неозначена форма — тире («а саме») — З8 с. 196–197; Вікі (інфінітив, «а саме»).
- Прикладку відокремлюємо: при особовому займеннику; поширену після означуваного; непоширену загальну назву після власної; зі словами тобто, себто, або / чи (= тобто), на ім'я, родом, за національністю, так званий; з «як» з відтінком причини. Не відокремлюємо «як» = «у ролі» — З8 с. 198–199; Вікі (те саме).
- Прикладки — коми, рідше тире (у кінці речення, для підкреслення, «а саме») — З8 с. 199; Вікі.
- Олена Пчілка — письменниця, перекладачка, мати Лесі Українки (l3 е4) — загальновідоме; З8 с. 203 (тест 461 №1 «Олена Пчілка, мати Лесі Українки, була письменницею»).
УП 2019 правил розділових знаків не містить (pitfalls-content.md) — тому друге джерело Вікі.

Свідомо не оцінюю (спірне):
- Відтінок причини у звороті **перед** означуваним словом (З8 «Наляканий громовицею, кінь…») — суб'єктивний; лише в `info` (l1 е7) і `fbText`; у завданнях звороти перед словом без коми — лише всередині речення, без можливого відтінку (забута кимось книжка, наляканого шумом лебедя, залитий сонцем степ, спечену на вогні картоплю).
- Кома чи тире при неузгодженому означенні та при прикладці в кінці речення — обидва допустимі; у `gaps` варіант тире не даю (лише «кома / ∅»). Інфінітивне означення — лише впізнавання (l2 е8 choice, l2 е9 pick), не вибір знака: З8 с. 197 впр. 446 №7 «хороша звичка записувати…» без тире — тире не завжди обов'язкове.
