### Факти (означення) з джерелами
- P_n = n!; перестановка — впорядкований набір усіх елементів: https://uk.wikipedia.org/wiki/Перестановка ; формули розміщень/комбінацій і 0! = 1 — тести/презентації 11 кл. naurok (https://naurok.com.ua/test/elementi-kombinatoriki-perestanovki-rozmischennya-kombinaci-1403227.html , https://naurok.com.ua/prezentaciya-elementi-kombinatoriki-104565.html — за витягами пошуку, сторінки віддають 403).
- A_n^k = n(n−1)…(n−k+1) = n!/(n−k)! (впорядкована вибірка різних елементів): https://uk.wikipedia.org/wiki/Розміщення_(комбінаторика) ; naurok (вище).
- C_n^k = n!/(k!(n−k)!), порядок неважливий: https://uk.wikipedia.org/wiki/Комбінація_(комбінаторика) ; naurok (вище). C = A : k! — випливає з формул (і показано в уроці моделлю).
- Класична ймовірність P = m/n, 0 ≤ P ≤ 1 — реєстр facts/math №104. Протилежна подія P(Ā) = 1 − P(A): конспекти ЗНУ/ХНЕУ (https://moodle.znu.edu.ua/ , https://pns.hneu.edu.ua/mod/resource/view.php?id=120021 — за витягами пошуку), у уроці виведено міркуванням (n − m сприятливих).
- Медіана (непарна — середній елемент впорядкованого ряду, парна — півсума двох середніх): https://uk.wikipedia.org/wiki/Медіана_(статистика) ; OpenStax Introductory Statistics 2e §2.5 https://openstax.org/books/introductory-statistics-2e/pages/2-5-measures-of-the-center-of-the-data
- Мода — найчастіше значення, може бути кілька: https://uk.wikipedia.org/wiki/Мода_(статистика) ; OpenStax §2.5 (вище).
- Розмах = найбільше − найменше: LibreTexts (укр., Lane 3.12 «Міри мінливості») https://ukrayinska.libretexts.org/ ; https://lms.smart-osvita.org/mod/quiz/view.php?id=32860 (за витягами пошуку).
- Середнє чутливе до одного великого значення, медіана — ні: OpenStax §2.5 (приклад 2.27). У уроці показано моделлю.
