# Слід

Інтерактивні уроки українською для 4–11 класів у форматі Brilliant: коротка проблема → здогадка → пояснення → завдання з миттєвим фідбеком. Працює без інтернету, щоб діти могли вчитися і в укритті під час тривоги.

## Запустити
```bash
python3 -m http.server 8000    # відкрити http://localhost:8000
```

## Що всередині
| | |
|---|---|
| `index.html`, `app/` | застосунок (ванільний JS, без залежностей) |
| `content/` | уроки як дані: один файл = один розділ |
| `tools/` | валідатор, метрики стилю, збирач, черга задач, плейтест |
| `style/` | стиль-гайди й профілі складності предметів |
| `memory/` | пам'ять для ШІ-агентів: довга (рішення, факти, глосарії) і коротка (handoff, inbox) |
| `tasks/` | черга задач для паралельних агентів |
| `docs/` | архітектура, схема контенту, педагогіка, процес, зображення, публікація |

## Працювати з ШІ-агентами
Відкрийте теку в Claude Code (або Codex / Cursor) — агент прочитає `AGENTS.md` (Claude — ще `CLAUDE.md`).
Типова сесія:
```
/parallel 5 hist 6        # 5 авторів паралельно пишуть історію 6 класу
/verify-section g6s1      # незалежна перевірка кожного розділу
/sync-style hist          # вирівняти стиль і складність
/handoff                  # зберегти пам'ять перед завершенням
```

## Перевірити контент
```bash
npm run check                       # build + validate + stats
python3 tools/playtest.py           # пройти всі уроки в браузері (потрібен Playwright)
```
