## Запити до рушія (не реалізовано; реалізоване звірено з CONTENT_SCHEMA §8 і test-lab.mjs)
- **Карти й схеми (SVG):** Північне Причорномор'я (g6s3–s4); анти / склавини; племінні союзи (g7s1); план протоміста (g6s2).
- **plane:** примітив `rays`, накладка-транспортир, внутрішній відступ навколо `view`.
- **numline:** лупа / підсвітка найближчої поділки для 0,01; підписи поділок звичайними дробами; накладання підписів точок.
- **fraction:** `shape: "dots"`; довгі підписи bar (обрізає 56 px); подвійна числова пряма для пропорцій і масштабу.
- **balance:** кнопки «зняти з обох шальок» + журнал рівнянь; від'ємні доданки; гирі-номінали (> 12 предметів).
- **column:** змінні поточного кроку в `show` (сума розряду, перенос). **solid:** поле `unit`. **chart:** kind «абак розрядів»; легенда «50%» без пробілу.
- **Шаблони:** `{n|plural:…}`; позначка «≈» для округленого; дужки лише для від'ємного числа.
- **Формули:** π не курсивиться, немає `pi` → π; після π ламається унарний мінус (`π − 1`).
- **Введення:** numDecimal — клавіатура без коми для цілих відповідей у темі десяткових дробів.
- **validate:** «★» вважає емодзі; осиротілі зображення; позиція зайвого в `multi`. **stats:** z-оцінки нестабільні для нового класу.
- **Продукт:** журнал кроків (де дитина кидає урок) — для тесту на дітях.
