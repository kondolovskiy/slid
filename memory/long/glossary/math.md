## Терміни
| Термін | Означення (формулювання для 4–6 кл.) |
|---|---|
| дріб, дробова риска | риска означає ділення: $3 : 4 = 3/4$ |
| чисельник | число над рискою: скільки частин узяли |
| знаменник | число під рискою: на скільки рівних частин поділили ціле |
| правильний дріб | чисельник менший за знаменник; дріб менший за 1 |
| неправильний дріб | чисельник більший за знаменник або дорівнює йому |
| мішане число | ціла частина + правильний дріб |
| неповна частка | результат ділення з остачею (скільки разів дільник уміщується) |
| остача | що лишилося; завжди менша за дільник |
| координатний промінь | промінь з початком 0 і одиничним відрізком |
| одиничний відрізок | відрізок від 0 до 1 |

## Правила (формулювання, щоб усі уроки казали однаково)
- Дріб від числа: **число ділимо на знаменник і множимо на чисельник**.
- Число за його дробом: **ділимо на чисельник і множимо на знаменник**.
- Порівняння: однакові знаменники → більший той, у кого більший чисельник; однакові чисельники → більший той, у кого **менший** знаменник.
- Додавання / віднімання з однаковими знаменниками: **чисельники додаємо (віднімаємо), знаменник залишаємо той самий**.
- Вилучення цілої частини: чисельник ділимо на знаменник з остачею; неповна частка — ціла частина, остача — чисельник.
- Мішане → неправильний: **ціла частина · знаменник + чисельник**.

### Правила (однакові формулювання)
- Порядок дій: дужки → множення й ділення зліва направо → додавання й віднімання зліва направо.
- Десяткові дроби в стовпчик: **кома під комою**.
- Відсотки від числа: **число ділимо на 100 і множимо на кількість відсотків**.
- 4 кл., частина від числа: **ділимо на кількість рівних частин**; ціле за частиною — **множимо**.
- 4 кл., одиниці: **великі в дрібні — множимо, дрібні у великі — ділимо (з остачею)**.
- Зустрічний рух (4 кл.): «щогодини зближуються на v₁ + v₂»; час = відстань : (сума швидкостей).
- Властивості рівнянь завжди з хвостом **«корені не змінюються»**.
- НСК — «найменше **натуральне** число, яке…» (без слова «натуральне» означення хибне).

### Правила (доповнення 5 кл.)
- Ділення на десятковий дріб: **перенести кому вправо в дільнику й діленому на стільки цифр, скільки їх після коми в дільнику; далі ділити на натуральне; бракує цифр — дописати нулі** (ms2l7; Істер).
