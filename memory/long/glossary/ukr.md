# Глосарій: українська мова

Терміни й нотація — як у підручнику Заболотних 5 кл. (З5, memory/long/facts/ukr.md) і Українському правописі. Створено 2026-11-02 (D-040). «Не вирішено» — наприкінці.

## Нотація
| Що | Пишемо | Приклад |

| звук | у квадратних дужках | [ж], [а] |
| м'який звук | ′ (U+2032) | [д′] |
| напівпом'якшений | ’ (U+2019) | [п’]ісок |
| подовжений | двокрапка | [н′:] — знання [знан′:а] (З5 с. 74) |
| наближення до іншого звука | маленька буква вгорі: `<sup>` | село [се<sup>и</sup>ло] (З5 с. 74); у `pick`/`split` (простий текст) транскрипцію з `<sup>` не використовуємо |

## Терміни (5 кл.)
| Термін | Формулювання для дитини |
|---|---|
| текст | два й більше речень, об'єднаних темою, основною думкою та граматично (З5 с. 221) |
| тема тексту | про що (кого) текст |
| основна думка | що автор хоче сказати, до чого спонукає |
| мікротема | частина загальної теми; зазвичай — абзац; найважливіше в ній — **тематичне речення**; слова з головним змістом — **ключові** (З5 с. 221) |
| лексичне значення | що означає слово, яке поняття називає |
| однозначне / багатозначне слово | має одне / кілька пов'язаних значень |
| пряме / переносне значення | основне / перенесене за схожістю |
| синоніми | слова, різні за звучанням, але однакові чи близькі за значенням (З5 с. 24) |
| антоніми | слова з протилежним значенням; завжди парами й тієї самої частини мови (З5 с. 27) |
| омоніми | слова, однакові за звучанням і написанням, але різні за значенням; значення не пов'язані (на відміну від багатозначного слова) (З5 с. 31–32) |
| пароніми | слова, близькі (не однакові) за звучанням, але різні за значенням і написанням: вистава — виставка (З5 с. 34) |
| основа / закінчення | частина без закінчення / змінна частина, що зв'язує слова в реченні |
| корінь | спільна частина спорідненених слів, головне значення |
| префікс / суфікс | частина перед коренем / після кореня, що творить нові слова |
| орфограма | місце в слові, де можна помилитися й треба знати правило |
| склад | частина слова, що вимовляється одним поштовхом повітря; скільки голосних — стільки складів |
| уподібнення | один приголосний стає схожим на сусідній |
| спрощення | випадання одного звука в групі приголосних ([ждн], [здн], [стл], [стн]); на письмі букву, як правило, не пишемо, але є винятки: *шістнадцять, контрастний* (вимовляємо без [т], пишемо т), *пестливий, кістлявий* (спрощення немає) (З5 с. 109–110) |
| чергування | заміна звука в тій самій частині слова в різних словах і формах |
| словосполучення | щонайменше два самостійні слова, одне з яких головне, а інше — залежне (питання від головного до залежного) (З5 с. 151) |
| граматична основа | підмет і присудок — головні члени речення; є й речення з одним головним членом (*Зимовий вечір.*) (З5 с. 159–160) |
| однорідні члени | залежать від того самого слова, відповідають на те саме питання й виконують однакову роль у реченні (З5 с. 178) |
| звертання | слово або сполучення слів, що називає того, до кого звертаються; не є членом речення; на письмі виділяємо комами (З5 с. 189) |

## Не вирішено
- [дж], [дз], [дз′] — один звук; підручник ставить дужку над двома буквами (З5 с. 76). **Вирішено (оркестратор, 2026-11-02):** у застосунку пишемо [дж], [дз], [дз′] без дужки (U+0361 у шрифті не перевірено) і пояснюємо словами: «дж — один звук, а не два», з посиланням, що в зошиті над ним ставлять дужку.
