# Глосарій: українська мова

Терміни й нотація — як у підручнику Заболотних 5 кл. (З5, memory/long/facts/ukr.md) і Українському правописі. Створено 2026-11-02 (D-040). «Не вирішено» — наприкінці.

## Нотація
| Що | Пишемо | Приклад |
|---|---|---|
| звук | у квадратних дужках | [ж], [а] |
| м'який звук | ′ (U+2032) | [д′] |
| напівпом'якшений | ’ (U+2019) | [п’]ісок |
| подовжений | двокрапка | [н′:] |
| буква | «ялинки» або **жирним** | буква «щ» |
| наголос у тексті уроку | U+0301 після голосного | листопа́д |
| частина слова | назва + дефіс | префікс **при-**, суфікс **-ськ-**, закінчення **-а**, корінь — **жирним** у слові |
| межі частин у `split` | `\|` | при\|мор\|ськ\|ий |
| питання | курсивом у дужках | (*хто?*) |
| неправильна форма (лише поруч із правильною) | `<s>…</s>` або «не так:» | |

## Терміни (5 кл.)
| Термін | Формулювання для дитини |
|---|---|
| текст | кілька речень, пов'язаних темою й основною думкою |
| тема тексту | про що (кого) текст |
| основна думка | що автор хоче сказати, до чого спонукає |
| мікротема | менша тема всередині тексту; зазвичай — абзац |
| лексичне значення | що означає слово, яке поняття називає |
| однозначне / багатозначне слово | має одне / кілька пов'язаних значень |
| пряме / переносне значення | основне / перенесене за схожістю |
| синоніми | слова з близьким значенням, що по-різному звучать |
| антоніми | слова з протилежним значенням |
| омоніми | слова, що однаково звучать і пишуться, але мають різні, не пов'язані значення |
| пароніми | слова, близькі за звучанням і будовою, але різні за значенням |
| основа / закінчення | частина без закінчення / змінна частина, що зв'язує слова в реченні |
| корінь | спільна частина спорідненених слів, головне значення |
| префікс / суфікс | частина перед коренем / після кореня, що творить нові слова |
| орфограма | місце в слові, де можна помилитися й треба знати правило |
| склад | частина слова, що вимовляється одним поштовхом повітря; скільки голосних — стільки складів |
| уподібнення | один приголосний стає схожим на сусідній |
| спрощення | у групі приголосних один випадає (у вимові й на письмі) |
| чергування | заміна звука в тій самій частині слова в різних словах і формах |
| словосполучення | два або більше повнозначних слів, пов'язаних за змістом і граматично (головне → залежне) |
| граматична основа | підмет і присудок |
| однорідні члени | відповідають на те саме питання й залежать від того самого слова |
| звертання | слово, що називає того, до кого говорять |
