# Реєстр: англійська мова (`eng`) — джерела, норми, факти

Що тут: **бібліографія** (програми, словники, нормативні акти), **норми**, які треба брати з джерела (форма слова, наголос, позначка BrE/AmE), і **факти про країни** для уроків (D-054; docs/design/english.md §6.1, §6.4). Автор бере формулювання звідси; нове — у нотатки задачі з URL, куратор переносить сюди. Створено 2026-11-19 (curate-eng-glossary). Нотація й написання — `glossary/eng.md`.

**Статуси:** `verified` — звірив верифікатор або куратор за першоджерелом; `self` — лише автор/дизайнер, без незалежної звірки; `вторинне` — першоджерело недоступне, звірено за вторинним; `не звірено`.

Правило: **форма слова, неправильне дієслово, ідіома, наголос, позначка BrE/AmE — щонайменше за CD або OALD**; верифікатор звіряє з двома. Тексти прикладів словників не копіюємо (власні приклади).

## Формат рядка
```
| № | Норма / факт (як писати в уроці) | Джерело (сигла + URL / сторінка) | Де вжито (урок, пул) | Статус | Дата, хто |
```
Факти про країни (дати, числа, назви) — як в історії (AGENTS.md §4 п. 2–3): одне формулювання, URL, статус. Розбіжність двох джерел — розділ «CONFLICT» нижче + `docs/teacher-questions.md` (TQ-NNN, D-049); сам не вирішуй.
