# Рішення (ADR)

Формат: `## D-NNN · дата · коротко` → Контекст / Рішення / Чому / Хто. Нові — внизу. Скасовані не видаляються, а позначаються «Скасовано D-XXX».

## D-001 · 2026-09-27 · Формат Brilliant, а не лише ШІ-тьютор
**Контекст:** діти не можуть регулярно відвідувати школу через тривоги; онлайн-навчання допомагає слабо.
**Рішення:** основа — інтерактивні уроки з детермінованою перевіркою відповідей. ШІ-тьютор — доповнення: кнопка «Не розумію» на екрані з помилкою.
**Чому:** перевірена послідовність і однозначна перевірка відповідей; тьютор корисний там, де сценарій закінчується.
**Хто:** Віктор (власник), Claude.

## D-002 · 2026-09-27 · Ванільний JS, офлайн, без збірки
**Рішення:** HTML + ванільний JS без залежностей; усі файли локально. Мобільна версія — обгортка Capacitor.
**Чому:** працює в укритті без мережі; простий WebView; агентам легко перевіряти контент без збирання.

## D-003 · 2026-09-27 · Спершу проблема, потім теорія
**Рішення:** кожен урок і тема починаються з проблеми; теорія подається як відповідь на неї. У кожного розділу й уроку є «навіщо».
**Хто:** Віктор (стале побажання до навчальних матеріалів).

## D-004 · 2026-09-27 · Без «життів» і покарань
**Рішення:** помилка → підказка і друга спроба → показ відповіді з поясненням. Мотивація — бали, серії, зірки, рівні, значки, денна ціль.
**Чому:** для дітей у стресових умовах покарання за помилку шкодить більше, ніж допомагає.

## D-005 · 2026-09-27 · Навігація: предмети → план року → уроки
**Рішення:** головний екран — список предметів (з картками «Продовжити» і «Зараз у школі»), далі план року предмета, далі карта уроків розділу. Не перемикач предметів угорі.
**Чому:** предметів буде більше ніж два (прохання Віктора).

## D-006 · 2026-09-27 · Клас — налаштування профілю, не рівень меню
**Рішення:** клас обирається при першому запуску й у профілі; фільтрує предмети й розділи. Повернення до тем попередніх класів — через передумови (`requires`, `pre`), а не через меню.

## D-007 · 2026-09-27 · Власна нотація формул замість KaTeX
**Рішення:** мініпарсер `$…$` у рушії: дроби стовпчиком, «·», «:», курсивні змінні, шрифт із засічками.
**Чому:** KaTeX потребує зовнішніх шрифтів (не працюють офлайн і в CSP артефакту); шкільна нотація (двокрапка для ділення) має бути саме такою.

## D-008 · 2026-09-27 · З 7 класу алгебра й геометрія — розділи одного предмета «Математика»
**Рішення:** поки що розділи з префіксом «Алгебра:» / «Геометрія:» у предметі math.
**Відкрите:** можливо, винести в окремі предмети. Для рушія це лише інші файли.

## D-009 · 2026-09-27 · Один файл = один розділ; план окремо
**Рішення:** `content/<предмет>/g<клас>-<id>.js` — розділ з уроками; `plan.js` — лише планові розділи. Розділ з тим самим id замінює запис плану.
**Чому:** паралельні агенти пишуть різні файли без конфліктів; план не треба редагувати під час написання.

## D-010 · 2026-09-27 · Статуси контенту draft → verified → approved
**Рішення:** `approved` ставить лише вчитель-людина. Верифікація — окремим агентом зі свіжим контекстом, не автором.

## D-011 · 2026-09-27 · Синхронізація стилю через еталони + метрики
**Рішення:** стиль-гайди предметів, еталонні розділи, спільні глосарій і реєстр фактів, профілі складності за діапазонами класів (`style/profiles.json`), звіт `tools/stats.mjs` із z-оцінками всередині «сім'ї» (предмет + діапазон класів). Профілі змінюються лише записом рішення тут.
**Калібрування:** 2026-09-27, на 28 уроках 4–5 кл. Профілі 7–11 кл. екстрапольовані — перекалібрувати після перших 10 уроків цих класів.

## D-012 · 2026-09-27 · Порядок тем і тижні — орієнтовні
**Рішення:** плани 4–11 кл. складено за загальною логікою курсів, а не за конкретним підручником. Перед показом звірити з модельними програмами НУШ; у продукті — завантаження календарного плану вчителем.

## D-013 · 2026-09-28 · PWA і GitHub Pages
**Рішення:** сайт — PWA (manifest, іконки, service worker з повним офлайн-кешем, генерується збирачем). Публікація — GitHub Pages через Actions з валідатором у CI. Репозиторій: github.com/kondolovskiy/slid.
**Чому:** встановлення на телефон без магазину застосунків і робота без мережі — ще до обгортки Capacitor.
**Хто:** Віктор.
