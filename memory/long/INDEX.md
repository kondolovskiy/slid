# Довга пам'ять — зміст

- `decisions.md` — рішення щодо продукту, педагогіки, архітектури й процесу (ADR). Читати перед будь-якою зміною рушія чи стилю.
- `pitfalls.md` — технічні пастки: шаблонні рядки й формули, CSP артефакту, зображення, WebView. Читати перед роботою з кодом чи зображеннями.
- `glossary/hist.md` — терміни, написання назв і дат для історії.
- `glossary/math.md` — нотація й терміни для математики.
- `facts/hist.md` — реєстр фактів історії (дати, імена, події) з джерелами й статусом перевірки.
- `facts/math.md` — конвенції й «факти» математики (правила, означення як у підручниках).
