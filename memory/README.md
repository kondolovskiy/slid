# Пам'ять ШІ-інфраструктури

Агенти не пам'ятають попередніх сесій. Усе, що має пережити сесію, лежить тут. Дві частини з різними правилами.

## Довга пам'ять — `memory/long/`
Стабільні знання, перевірені й узгоджені. Читають усі, **пише лише куратор** (роль memory-curator або людина).

| Файл | Що | Коли дописують |
|---|---|---|
| `INDEX.md` | зміст довгої пам'яті, по рядку на файл | при додаванні файлу |
| `decisions.md` | рішення (ADR): що вирішили, чому, хто, коли | коли людина ухвалила рішення або його прийнято в сесії |
| `pitfalls.md` | технічні й процесні пастки та як їх обійти | коли проблема трапилась ≥ 2 рази або коштувала > 10 хв |
| `glossary/<предмет>.md` | терміни, нотація, написання назв — одна форма | коли з'являється новий термін або розбіжність |
| `facts/<предмет>.md` | реєстр фактів: формулювання, дата, джерело, статус перевірки | коли факт перевірив верифікатор (або вчитель) |

Правила:
- Коротко й по суті. Файл > 400 рядків — розбити за темами (напр. `facts/hist-7.md`).
- Кожен запис має дату і джерело/автора. Нічого не видаляємо мовчки: застаріле позначаємо `~~закресленням~~` + причина.
- Суперечність (два джерела, дві дати) не вирішується на рівні пам'яті — вона йде у handoff як відкрите питання до людини.

## Коротка пам'ять — `memory/short/`
Робочий стан, живе від сесії до сесії й регулярно очищується.

| Файл | Що | Хто пише |
|---|---|---|
| `handoff.md` | **знімок стану**: що зроблено, що в роботі, що далі, відкриті питання. ≤ 80 рядків. Перезаписується в кінці кожної сесії | оркестратор / куратор |
| `inbox.md` | вхідні від агентів під час роботи: нові факти, пропозиції до стилю, конфлікти, баги. **Лише дописувати**, по рядку | будь-який агент |
| `sessions/<дата>-<n>.md` | журнал сесії: мета, що зроблено, рішення, що лишилось. ≤ 1 сторінка. Тримаємо останні 10 | куратор |

## Цикл
```
початок сесії:  handoff.md → INDEX.md → потрібні файли long/
під час роботи: агенти дописують у inbox.md (не в long/!)
кінець сесії:   /handoff → куратор переносить inbox → long/, пише sessions/…, перезаписує handoff.md, очищує inbox
```

## Формат рядка в inbox
```
- 2026-09-28 writer-g6s1 FACT: Товста Могила розкопана 1971 р. (Б. Мозолевський) — https://… — урок g6s3-l3
- 2026-09-28 writer-g6s2 STYLE: пропоную дозволити order з 7 пунктів для хронології — причина…
- 2026-09-28 verifier-s2 CONFLICT: у facts/hist.md Острозька Біблія 1581, у задачі 1580 — перевірено: 1581 (джерело)
- 2026-09-28 writer-m5 ENGINE: потрібен тип «ввести десятковий дріб» — поле number приймає лише цифри
- 2026-09-28 orchestrator BUG: …
```
Типи: FACT, TERM, STYLE, CONFLICT, ENGINE, BUG, IDEA.
