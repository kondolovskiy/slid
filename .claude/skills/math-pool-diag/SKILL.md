# Пули вправ і тести рівня (math)

Пул (`SLID.pool`) — задачі для тренування після уроку; дитина **записує** відповідь. Тест рівня (`SLID.diag`) — діагностика класу.
Задача — `tasks/doing/<task-id>.md` (зазвичай `write-math-pool-*`, `write-math-diag-*`, `revise-math-pool-*`).

## 1. Прочитай
- docs/CONTENT_SCHEMA.md: §10 (пул: поля, `answerKind`, одиниці, бюджет обчислень) або §9 (тест рівня: проби, `rev`, HALF).
- docs/PERSONALIZATION.md (як пул і тест працюють у застосунку).
- decisions.md: D-030 (пороги, answerKind), D-031 (назва перед координатами/множиною), D-032 (SRS з тесту, OK/HALF), D-039 (одиниці).
- glossary/math.md (нотація, сигли джерел: mer5, g4a/g4b, l4a/l4b, a7, mer7g, a8, mer8g, a9, mer9g, m10, m11).
- facts/math.md (бібліографія, сторінки, хибні умови підручників).
- `memory/long/pitfalls-math.md`: «Формати відповідей пулів», «Підручники: сторінки», «Контент і формули» (01.11).
- Сусідні пули того ж класу як еталон.

## 2. Правила змісту
- **Задачі — з реальних джерел** (`src: "<сигла> №<номер>"`, `srcPage` — друкований номер сторінки). Не вигадувати; хибну умову підручника не брати або брати «більш правильну» з того ж джерела.
- Сторінка: Мерзляк 5 (2022) PDF = друк. + 1; Мерзляк/Якір 7–9 (2024–2026) PDF = друк.; колонтитул звіряй завжди. Автори — з титулу PDF.
- Текстовий шар PDF губить `√` і знаки — ключі й корені звіряй зі сторінкою-зображенням.
- 6–8 задач на урок (≈ 3 рівня 1, 2–3 рівня 2, 1–2 рівня 3); поняттєвий урок — виняток, мінімум 5 з поясненням у нотатках (tasks/README-math-personalization.md); `lesson` — урок розділу (не boss); `sk` — навичка уроку.
- Числова відповідь — завжди `type: "answer"`. «Спрости / розклади» — завжди з `form`. `1/2x` читається як `x/2`; `√` бере один множник.
- `steps` — 2–5 коротких рядків розв'язання.
- Умова посилається на рисунок («на рисунку», «за графіком», «на кресленні») чи геометрія з позначеннями, яких немає на екрані, — на тому ж екрані ілюстрація (статичний `lab` plane `axes: false` / `solid` / `chart`, `fig`, `img`): точно за умовою, шукане не підписане, дуга кута без числа — `label: false`. validate попереджає лише про пряме посилання на рисунок; геометрію без рисунка показує лише `node tools/fig-audit.mjs` (CONTENT_SCHEMA §6).
- TeX у `"…"` — лише з `\\` (`"\\frac"`); validate дає помилку на одиночний бекслеш.
- **id пулу й задач — ключі прогресу**, не перейменовувати. Зміна `sk` задачі → рядок у `SK_RETAG` (app/learn.js) — це вже інженерна зміна (скіл `engine-change`).
- **Тест рівня:** заміна проби на тому самому індексі — лише з `rev` (CONTENT_SCHEMA §9), інакше перервані тести змішають відповіді.
- Формат, якого немає в рушії, — не обходь: рядок ENGINE в inbox.

## 2а. Тест рівня з мови (ukr: `content/ukr/diag-g*.js`, engine-diag-lang-types)
Пулів для ukr немає — цей розділ лише про тест рівня. Разом зі скілом `content-author` (стиль і норми ukr).
- Прочитай: style/ukr.md, glossary/ukr.md, facts/ukr.md (джерела З5–З7), decisions D-040, D-041/D-042 (як помилку оцінюємо лише ненормативне і за правописом/підручником, і за словником; вибір між двома нормативними варіантами — не оцінюється), D-045 (`sk`: `gram` — форми, `orth` — букви й написання; відміни й дієвідміни латиницею I–IV), D-047.
- Мовні вправи в тесті (CONTENT_SCHEMA §9): `gaps` ≤ 3 пропуски, `stress` ≤ 3 слова, `pick` ≤ 20 слів-кнопок і ≤ 3 правильні, `split` — одне слово, `word`. Вердикт — правильно все або ні; позначок і показу відповіді немає. Наголос — лише слова з одним нормативним наголосом (звір зі словником).
- `fbOk`, `fbText`, `hint` у тесті не потрібні (попередження validate).
- Немає уроків класу нижче (ukr 5 кл.) — передумови `baseline: true` за програмою попередніх класів (джерело — у нотатки).

## 3. Перевір
```bash
node tools/validate.mjs --pool <id>        # або --diag <id>; 0 помилок
python3 tools/test-answer-ui.py --suite content --pool <id>    # або --diag <id>; приклади з підказок не мають зараховуватися
node tools/personalization-qa.mjs          # покриття матриці персоналізації (docs/PERSONALIZATION_QA.md)
node tools/diff-answers.mjs --grades <N>   # за зміни ключів: перевір, що кількість вправ ненульова
```
Під паралельним запуском чужий напівзаписаний `pool-*.js` ламає validate для всіх пулів — тоді прогін на копії дерева у своїй підтеці scratchpad.

## 4. Здай
Нотатки задачі: задачі → джерело → сторінка; сумнівні умови; формати, яких бракує. Рядки FACT/ENGINE в inbox. `node tools/claim.mjs move <task-id> review` — далі незалежний верифікатор (`content-verify`).
