# Пули вправ і тести рівня (math, ukr, eng)

Пул (`SLID.pool`) — задачі для тренування після уроку; дитина **записує** відповідь. Тест рівня (`SLID.diag`) — діагностика класу.
Задача — `tasks/doing/<task-id>.md` (зазвичай `write-math-pool-*`, `write-math-diag-*`, `revise-math-pool-*`; мовні — `write-ukr-*`, `write-eng-pool-*`, `write-eng-diag-*`). §1–2 — математика; ukr — §2а–2б, eng — §2в.

## 1. Прочитай
- docs/CONTENT_SCHEMA.md: §10 (пул: поля, `answerKind`, одиниці, бюджет обчислень) або §9 (тест рівня: проби, `rev`, HALF).
- docs/PERSONALIZATION.md (як пул і тест працюють у застосунку).
- decisions.md: D-030 (пороги, answerKind), D-031 (назва перед координатами/множиною), D-032 (SRS з тесту, OK/HALF), D-039 (одиниці).
- glossary/math.md (нотація, сигли джерел: mer5, g4a/g4b, l4a/l4b, a7, mer7g, a8, mer8g, a9, mer9g, m10, m11).
- facts/math.md (бібліографія, сторінки, хибні умови підручників).
- `memory/long/pitfalls-math.md`: «Формати відповідей пулів», «Підручники: сторінки», «Контент і формули» (01.11).
- Сусідні пули того ж класу як еталон.

## 2. Правила змісту
- **Задачі — з реальних джерел** (`src: "<сигла> №<номер>"`, `srcPage` — друкований номер сторінки). Не вигадувати; хибну умову підручника не брати або брати «більш правильну» з того ж джерела.
- Сторінка: Мерзляк 5 (2022) PDF = друк. + 1; Мерзляк/Якір 7–9 (2024–2026) PDF = друк.; колонтитул звіряй завжди. Автори — з титулу PDF.
- Текстовий шар PDF губить `√` і знаки — ключі й корені звіряй зі сторінкою-зображенням.
- 6–8 задач на урок (≈ 3 рівня 1, 2–3 рівня 2, 1–2 рівня 3); поняттєвий урок — виняток, мінімум 5 з поясненням у нотатках (tasks/README-math-personalization.md); `lesson` — урок розділу (не boss); `sk` — навичка уроку.
- Числова відповідь — завжди `type: "answer"`. «Спрости / розклади» — завжди з `form`. `1/2x` читається як `x/2`; `√` бере один множник.
- `steps` — 2–5 коротких рядків розв'язання.
- Умова посилається на рисунок («на рисунку», «за графіком», «на кресленні») чи геометрія з позначеннями, яких немає на екрані, — на тому ж екрані ілюстрація (статичний `lab` plane `axes: false` / `solid` / `chart`, `fig`, `img`): точно за умовою, шукане не підписане, дуга кута без числа — `label: false`. validate попереджає лише про пряме посилання на рисунок; геометрію без рисунка показує лише `node tools/fig-audit.mjs` (CONTENT_SCHEMA §6).
- TeX у `"…"` — лише з `\\` (`"\\frac"`); validate дає помилку на одиночний бекслеш.
- **id пулу й задач — ключі прогресу**, не перейменовувати. Зміна `sk` задачі → рядок у `SK_RETAG` (app/learn.js) — це вже інженерна зміна (скіл `engine-change`).
- **Тест рівня:** заміна проби на тому самому індексі — лише з `rev` (CONTENT_SCHEMA §9), інакше перервані тести змішають відповіді.
- Формат, якого немає в рушії, — не обходь: рядок ENGINE в inbox.

## 2а. Тест рівня з мови (ukr: `content/ukr/diag-g*.js`, engine-diag-lang-types)
Про пули ukr — розділ 2б. Разом зі скілом `content-author` (стиль і норми ukr).
- Прочитай: style/ukr.md, glossary/ukr.md, facts/ukr.md (джерела З5–З7), decisions D-040, D-041/D-042 (як помилку оцінюємо лише ненормативне і за правописом/підручником, і за словником; вибір між двома нормативними варіантами — не оцінюється), D-045 (`sk`: `gram` — форми, `orth` — букви й написання; відміни й дієвідміни латиницею I–IV), D-047.
- Мовні вправи в тесті (CONTENT_SCHEMA §9): `gaps` ≤ 3 пропуски, `stress` ≤ 3 слова, `pick` ≤ 20 слів-кнопок і ≤ 3 правильні, `split` — одне слово, `word`. Вердикт — правильно все або ні; позначок і показу відповіді немає. Наголос — лише слова з одним нормативним наголосом (звір зі словником).
- `fbOk`, `fbText`, `hint` у тесті не потрібні (попередження validate).
- Немає уроків класу нижче (ukr 5 кл.) — передумови `baseline: true` за програмою попередніх класів (джерело — у нотатки).

## 2б. Пул тренування з мови (ukr: `content/ukr/pool-g<клас>-<розділ>.js`, engine-pool-lang)
Задача — `write-ukr-pool-*` (`make-tasks --write-pool --subject ukr`). Разом зі скілом `content-author`. Контракт — CONTENT_SCHEMA §10 «Пули мовних предметів».
- Прочитай те саме, що для тесту рівня (2а), і **уроки розділу повністю**: вправа тренує лише те, що урок пояснив (D-019); `sk` вправи — з `sk` екранів її уроку.
- id пулу `p<розділ>` (`pu5s1`), id вправ `a01`… — ключі прогресу. Розділи «Пишемо самі…» — без пулу.
- Типи: переважно `gaps` (≤ 6 пропусків), `stress` (≤ 6 слів), `pick` (≤ 40 слів), `word`, `split`; `sort` / `order` — класифікації й порядок; `choice` / `multi` — лише поняттєві питання, не замість правопису. Межі тесту рівня (2а) тут не діють. Поля математики (`unit`, `answerKind`, `gen`…) і `hyp`/`poll` — помилка.
- 4–6 вправ на урок з оцінюваними екранами (~2 рівня 1, 2 рівня 2, 1–2 рівня 3); `steps` — пояснення 1–4 рядки (правило + розбір: дитина бачить його як «Пояснення»), `hint` для рівнів 2–3.
- Часткового зарахування немає: вправа з кількома пропусками зараховується, лише коли правильні всі. Не склеюй різні правила в один `gaps` — одна помилка «з'їсть» тему в SRS.
- Джерела — реальні вправи підручника (З<клас> впр. N, `srcPage`; `adapted: true`, якщо речення скорочено); норма — D-041/D-042: вибір між нормативними варіантами не оцінювати; наголос — за словником.

## 2в. Англійська (eng: `content/eng/diag-g<клас>.js`, `content/eng/pool-g<клас>-<розділ>.js`)
Разом зі скілом `content-author`, розділ «Англійська» (мова, BrE, словники, друга правильна відповідь, без звуку й IPA, авторське право — там). Контракт — CONTENT_SCHEMA §4.1 («`word` англійською», `stress` складами), §9, §10 «Пули мовних предметів»; дизайн — docs/design/english.md §7. Механіка ukr (2а–2б) діє, крім сказаного тут.
- **id — ключі прогресу:** тест рівня `dge<клас>` (dge4…dge11), пул `p<розділ>` (`pe4s1`, як у CONTENT_SCHEMA §10), вправи `a01`….
- **Механіка (engine-eng-diag-pool):** `build` і `match` дозволено в тестах рівня й пулах; межі тесту — `build` ≤ 7 плиток разом з `extra` і ≤ 1 пастка, `match` ≤ 4 пари (CONTENT_SCHEMA §9); у пулі — як в уроці. Літери A, B, C у тесті рівня ставить рушій (`OPT_LETTERS_LANG`, engine-eng-validate). **dge4** — перший клас предмета, уроків нижче немає: `pre` — теми вхідного рівня Pre A1–A1 (ТОП 3–4, 3 кл.) з `baseline: true`, `lessons: []`, `for` — id **розділів** 4 кл., куди веде тема, `see` — 1–3 id **уроків** e4s*, де тему повторюють (загальна механіка `baseline` — CONTENT_SCHEMA §9, як у math 4 і ukr 5; для eng перевірено в engine-eng-diag-pool). write-eng-diag-g4 і пули eng залежать від engine-eng-diag-pool — до її приймання рецензентом не беремо (`depends_on` claim.mjs не перевіряє — дивись сам). `pre` у dge5…dge11 — уроки попереднього класу.
- **Вправи власні:** правило «задачі — з реальних джерел» (§2) для eng не діє — вправ, текстів і речень підручників CUP/OUP не беремо (docs/design/english.md §8). Але `src` у пулі обов'язковий (validate: `src` = «<id джерела з `sources`> <посилання>», `sources` — `id`, `title`, `url`). **Правило для eng:** `sources` — лише програма класу: `id` — одна з латинських сигл `top34` (ТОП 3–4, 4 кл.), `mpim` (МП-ІМ, 5–9 кл.), `p1407` (П1407, 10–11 кл.) — однакова в усіх пулах eng; `title` і `url` PDF — з facts/eng.md «Джерела»; **`program: true`** — тоді тренування не показує під вправою «Джерело: <програма>» (validate без нього попереджає; CONTENT_SCHEMA §10); `src` вправи — «<сигла> с. N», де N — сторінка програми з темою чи граматикою, яку вправа тренує (сторінки — facts/eng.md, звіт плану свого класу); `srcPage` і `adapted` не ставимо. Номерів вправ не вигадуємо; словники, за якими звірено форми, — у нотатки задачі, не в `src`. Формат не підходить — рядок ENGINE/STYLE в inbox, не обхід.
- **Лише матеріал уроків розділу (D-019):** слова, форми й правила, що були в уроці; `sk` — з екранів уроку (`read`, `vocab`, `gram`, `phon`, `func`, `write`, `cult`). Тест рівня — рівень класу за програмою (4 кл.: Pre A1 → A1).
- **Однозначність важливіша, ніж в уроці:** у тесті рівня немає пояснення, у пулі немає часткового зарахування — друга правильна BrE-відповідь (will / be going to — і для прогнозу за ознаками, артиклі, прийменники, скорочення) має або бути в ключі (масив `answer`, `contractions: true`), або бути відсічена контекстом. Нормалізація рушія (AmE-правопис з приміткою, кирилиця-двійник, `contractions`) — лише у `word`; у `gaps`/`choice`/`pick` варіант порівнюється точно, тож AmE-написання не роби хибним варіантом. AmE-лексику рушій не нормалізує ніде (TQ-125). Кінцевого `.!?` у ключі `word` не став, якщо знак — не предмет вправи: він тоді обов'язковий у відповіді. Час — обидва записи, якщо вправа не вчить перехід 12/24 год. (CONTENT_SCHEMA §4.1).
- **Типи:** `gaps`, `word`, `pick`, `stress` (`"+pho|to|graph"`, наголос — за словником), `split`; `choice` / `multi` — поняттєві питання й «звук ↔ буквосполучення» (без IPA); варіанти A, B, C ставить рушій. Аудіювання немає й не імітуємо.
- Усе англійською; `fbOk`/`fbText`/`hint` у тесті не потрібні, `steps` пулу — англійською рівня класу; `uk` у тесті й пулі — помилка validate.

## 3. Перевір
```bash
node tools/validate.mjs --pool <id>        # або --diag <id>; 0 помилок
python3 tools/test-answer-ui.py --suite content --pool <id>    # або --diag <id>; приклади з підказок не мають зараховуватися
node tools/personalization-qa.mjs          # покриття матриці персоналізації (docs/PERSONALIZATION_QA.md); пул ukr — --pool <id> (без матриці: ≥ 3 вправи й рівні 1–3 на урок)
node tools/diff-answers.mjs --grades <N>   # за зміни ключів: перевір, що кількість вправ ненульова
```
Під паралельним запуском чужий напівзаписаний `pool-*.js` ламає validate для всіх пулів — тоді прогін на копії дерева у своїй підтеці scratchpad.

## 4. Здай
Нотатки задачі: задачі → джерело → сторінка; сумнівні умови; формати, яких бракує. Рядки FACT/ENGINE в inbox. `node tools/claim.mjs move <task-id> review` — далі незалежний верифікатор (`content-verify`).
