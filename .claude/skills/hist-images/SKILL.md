# Зображення в уроках (Вікісховище, D-027)

Правила — docs/IMAGES.md; пастки — pitfalls.md («Зображення: Вікісховище», «Вікісховище: 429 і хибні описи», «Звідки качати зображення», «Ліцензії», «Хибні описи Commons», «Підписи (`cap`) і завдання»).
Задача — зазвичай `tasks/doing/images-<предмет>-<id>.md`.

## 1. Перш ніж шукати
- Пошукай уже перевірене зображення в `img/` інших класів (5 кл. часто має те, що треба 7–8 кл.).
- Реєстр `memory/long/facts/hist.md`: підписи зображень D-027 (№221–313) — бери формулювання звідти.

## 2. Пошук і ліцензія
- Лише суспільне надбання, CC0, CC BY, CC BY-SA. Головне джерело — Commons.
- API: `https://commons.wikimedia.org/w/api.php?action=query&generator=search&gsrsearch=<запит>&gsrnamespace=6&prop=imageinfo&iiprop=url|extmetadata&iiextmetadatafilter=LicenseShortName|Artist&format=json`. Ліцензію й автора — з `extmetadata`, не вгадувати.
- Файл з uk.wiki може бути локальним (Commons дає MISSING) — ліцензію перевір на uk.wiki.
- Автор/ліцензія, яких не знайти, — не брати. Сучасні пам'ятники й будівлі (автор живий або помер < 70 років тому) — не брати: в Україні немає свободи панорами.
- Без впізнаваних приватних осіб (крім публічних подій і історичних постатей). Чутливі теми (війни, репресії, голод) — документи, місця пам'яті, портрети, плакати, карти; без натуралістичних фото жертв.
- **Описи Commons часто хибні** (дати, імена, тип документа): дату й титул звіряй із самим документом на фото і з ≥ 2 джерелами.
- Музейні предмети — з музею: Met Collection API (`collectionapi.metmuseum.org/public/collection/v1/objects/<id>` → `primaryImage`, CC0), ikmk.smb.museum (PD Mark). Документи ООН із символом (A/RES/…) — суспільне надбання.

## 3. Завантаження
- **Лише мініатюри з `thumb.wikimedia.org`**, не `upload.wikimedia.org` (429). Паузи 20–25 с між файлами, ≤ 2 спроби на файл, **≤ 2 агенти з фото одночасно**.
- PDF-скани на Commons — мініатюра сторінки `thumb/h/hh/Name.pdf/page1-960px-Name.pdf.jpg`.
- Нейтральний `User-Agent` (напр. `SlidEduBot/0.1 (offline lessons project)`); жодних email, імен чи акаунтів у запитах.
- Тимчасові файли — у власній підтеці scratchpad (`<scratchpad>/<task-id>/`), не в спільній `dl/`.
- Формат: JPEG, ширина ≤ 1000 px, якість ≈ 0,75–0,8, ≤ 250 КБ. Тека: `img/<предмет>/<id розділу>/<назва>.jpg`.

## 4. В уроці
- `img` працює на зміст: джерело для завдання або проблема `intro`, не декор. На екрані — одна ілюстрація (img | svg | fig | lab). svg/fig вимогу D-027 не закривають.
- Вертикальні карти й документи — `tall: true` (чорне тло) або `fit: true` (біле тло), інакше рушій обріже до 300 px.
- `cap`: що, де, коли; для репродукцій — автор і дата. На оцінюваному екрані `cap` не має дослівно містити правильний варіант — звір слова `cap` з `opts` цього й наступного екрана.
- Цитата біля скану: «мова оригіналу, сучасними літерами», а не «правопис оригіналу». Картина на пізніший легендарний сюжет — «сюжет — переказ про …, пізніший за події».
- `credits` розділу: `[назва, автор, ліцензія, URL сторінки файлу]`.
- Завдання на основі фото — чесне (D-019): кожен правильний пункт видно на фото, інакше — «з попереднім екраном».
- Змінені уроки повертай у `status: "draft"` — далі незалежний верифікатор.

## 5. Перевір і здай
```bash
node tools/validate.mjs --section <id>     # 0 помилок і жодного D-027
```
Нотатки: урок → файл → ліцензія → URL; змінені завдання; сумнівні місця; для уроку без вільного зображення — перелік перевіреного (не бери випадкове). Рядки FACT в inbox. `node tools/claim.mjs move <task-id> review`.
Видалене зображення лишається в `sw.js` до build — нагадай оркестратору.
