## Уточнення для авторства

- dg9 / `polygon`: `g8m6l1` навчає суму кутів і відновлення числа сторін. Для «кута правильного многокутника» треба дати рівність усіх кутів у самій умові; термін «правильний» цей урок не вводить. Простіше друга проба на знаходження n за сумою.
- dg10 / `func`: «Прочитати область» двозначне. `g9m3l1` містить область **значень**, але не вводить область визначення. Уточнити в пробі область значень за графіком; не складати пробу про D(f), спираючись на цей item.lesson.
- Для concept-уроків JSON `formats: [number]` читається як вузьке обмеження, хоча вступ дозволяє choice/multi. Перед авторством явно узгодити поле форматів із дозволеними поняттєвими вправами; це не підстава штучно добирати шість однакових числових завдань.

## Межі висновку

Наявність pending одного класу не блокує інші прийняті required-теми. Висновок не підтверджує майбутні 6–8 вправ на урок чи час 10–15 хв: вправ ще немає, час правильно позначено гіпотезою. Чинний dg6 не переписувати в межах цього виправлення; його окремий борг маршрутизується через refine-math-diag-g6-coverage.

## Повторна перевірка виправлень v2

Переглянуто diff MD/JSON і фінальні поля діагностик. `tri-angles` тепер перевіряє можливість трикутника за двома кутами; `root` — корінь добутку/частки повних квадратів; `polygon` — число сторін за сумою; `func` — явно область значень за графіком. Це відповідає вказаним урокам повторення.

`dg10.area` тепер спирається на `ms4l1`: площа прямокутника та знаходження сторони. Єдиний `for` — g10m6, `forEvidence` — g10m6l4. Незалежно відкрито всі екрани g10m6l4: загін біля стіни з 20 м огорожі, S = w(20 − 2w), обчислення S(5) = 50. Застосування опори реальне.

У всіх нових cur задано конкретні `coverageObjectives`; перевірено їх збіг із `outro.learned` відповідного живого уроку. Для широкого g11m4l1 це одночасно призма, лічба елементів і апофема піраміди; для g11m5l1 — перестановки, розміщення й комбінації. Контракт вимагає одного multi/sort з усіма компонентами. Якщо автор не може реалізувати достатню пробу, він повертає вибір куратору, а не використовує неіснуюче вимкнення known. Зіставлення з фактичними екранами для розглянутих вище широких уроків підтверджує зміст. Остаточну дієвість конкретних завдань перевіряє майбутній незалежний верифікатор тесту.

Обсяг незмінний: 182 тематичні уроки, 169 required / 7 optional / 6 pending. Активні задачі та README більше не посилаються на v1. Бажане уточнення formats також внесено: у дев’яти поняттєвих рядках (g4m5l4, ms0bl1, ms4l2, g7m2l1, g7m4l1, g7m8l1, g7m8l3, g10m2l2, g10m4l1) перевірено choice/multi поряд із number. Числові вправи на довжини/кількість елементів лишаються допустимими; поняттєві властивості більше не обмежено числовою відповіддю.
