## 5. Правки (зроблені)
1. l1 word: у body додано «Use a verb from “Hardware and software”.» — відсікає died / frozen / broken down.
2. l2 info Diia і fbText l2 choice: «equal to a paper one» → «equal to an ordinary one».
3. l4 info «Imagined: if … not, not unless» → «Imagined: if … not»: правило «unless не для протилежного реальності» і «Not: Unless I had…» прибрано; натомість — if + Past Simple з not, no would в if-частині («Not: If I wouldn’t have a laptop» — CD Grammar conditionals), unless «is best for real, possible situations». l4 choice: дистрактор «Unless I had my phone…» → «If I wouldn’t have my phone…», hint і fbText узгоджено; `learned` п. 3 переформульовано.
4. l7 Task 7 pick: «[Unless] I had a phone…» → «If I [wouldn’t have] a phone, I [!would read] more books.»; hint, fbBad, fbText узгоджено (опора — l4 info, l5 info «Not: If I would be you»). l5 match: «back up my files» → «back up your files».
5. l7 Task 4: дистрактор «won’t work» → «don’t work»; fbBad узгоджено.
6. Коментар-шапка (рядки 7, 21) — оновлено під правки; `status: "verified"` у 7 уроках.
