## 6. Педагогіка, вік, стиль
- Кожен урок: intro з проблемою → здогадка `hyp` (l1, l3, l4) або завдання з опорою → теорія → 4–7 завдань → «Знайди помилку» → «Фінал». Підказки навідні, відповіді не видають.
- Чутливе: лемур Байрактар — нейтрально, без агітації (як у З6). Неприйнятного для віку немає.
- Нагадування про стилі в l4 — коректне, коротке; стилі в застосунку 5 кл. не вивчали (рядок STYLE автора в inbox).
- `validate --section u6s3`: 0 помилок, 0 попереджень. `playtest --section u6s3`: 6/6 уроків пройдено. `stats`: u6s3l4 longWordShare z = 3.1 — терміни теми («офіційно-діловий», «суспільно-політичні»), пояснено автором; прийнятно.
