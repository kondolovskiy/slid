## Підсумок

Усі 8 вправ узято **дослівно з main**. Із PR #6 узято лише повніші бібліографічні описи `sources`: «закладів загальної середньої освіти», гриф «наказ МОН № 111 від 27.01.2026», «PDF-дзеркало 4book.org». Діапазони сторінок main лишилися. Обидва описи я звірив зі зворотом титулу обох PDF. Вправ PR #6 у фінальному файлі немає.

Чому так:
1. **Формат.** Main уже пройшов шлях, який PR #6 лише пропонує. Перша верифікована версія main майже збігалася з PR #6: 50 : 7, 65 : 9 і 62 аркуші питали лише частку або лише остачу. Потім ці вправи замінили на divrem: a09 29 : 6, a10 49 : 8, a11 «йогурт». CONTENT_SCHEMA §10 тепер прямо вимагає: «Одна вправа "знайди частку й остачу" — це одна задача divrem, а не дві». У PR #6 a01–a03 і a05 цю вимогу порушують, бо беруть половину відповіді з вправ l4a №5, g4a №161 і №165(1), де просять обидва числа. Divrem природніший: учень пише «4 ост. 5», як на екрані 2 уроку (`17 : 5 = 3 (ост. 2)`).
2. **Опора на урок (D-019).** Урок m4a не вводить слова «ділене», є лише «неповна частка», «остача» й «дільник» (`grep` по content/math/g4-m4s1.js). Main це врахував: a05 питає «Яке число ділили?», а термін пояснено лише в steps. У PR #6 термін «ділене» стоїть в умові a04 («Яке було ділене?») і a06 («Знайди невідоме ділене»), а також у hint a08. Верифікатор PR #6 цього не помітив.
3. **Стабільність id.** Main уже в origin/main, тож id a03 і a05–a11 могли потрапити в прогрес учнів (ключ: pool id + item id). Id PR #6 a01–a08 збігаються за назвою з іншими вправами main. Наприклад, a03 у main — це «найбільша остача при діленні на 8», а в PR #6 — 65 : 9. До того ж a01, a02 і a04 main видалив і заборонив повторно використовувати. Будь-яку вправу PR #6 довелося б перейменувати (a12+). Від цього прогрес учнів не зламався б, але вигоди не видно (див. таблицю).
