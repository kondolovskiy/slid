# Архітектура

## Принципи
- **Без залежностей і збірки.** Ванільний JS + HTML/CSS. Відкривається будь-яким браузером і в WebView.
- **Офлайн за замовчуванням.** Уроки, картинки й прогрес лежать на пристрої. Це головна вимога: діти вчаться в укриттях під час тривог.
- **Рушій окремо від змісту.** `app/` не знає жодного предмета. Новий предмет чи клас — лише нові файли в `content/`.
- **Контент як дані.** Урок — декларативний опис екранів (docs/CONTENT_SCHEMA.md), який можна перевіряти автоматично.

## Файли й порядок завантаження
```
index.html              оболонка + CSS (токени кольорів, світла/темна тема)
  app/registry.js       window.SLID: subject() / section() / soon() / finalize()
  content/subjects/*.js метадані предметів
  content/<предмет>/plan.js      плановані розділи (без уроків)
  content/<предмет>/g*-*.js      розділи з уроками (замінюють записи плану з тим самим id)
  content/catalog.js    предмети «скоро»
  content/<предмет>/diag-g*.js   тест рівня класу (SLID.diag), docs/CONTENT_SCHEMA.md §9
  app/lab.js            лабораторія: інтерактивні моделі (графіки, геометрія, терези…), docs/CONTENT_SCHEMA.md §8
  app/learn.js          персоналізація: тест рівня, план, повторювані помилки (чиста логіка), docs/PERSONALIZATION.md
  app/app.js            рушій (викликає SLID.finalize())
```
Порядок прописує `tools/build.mjs` (між маркерами `CONTENT:START/END`). Список дублюється в `content/manifest.json` для інструментів.

## Рушій (`app/app.js`)
- **Формули**: `mathHTML()` / `fmt()` — власний мініпарсер `$…$` → HTML (дроби стовпчиком, ·, :). KaTeX не використовується: йому потрібні шрифти, які не вантажаться офлайн і блокуються в артефакті.
- **Навігація**: вкладки «Навчання / Прогрес / Профіль». «Навчання»: предмети → план року (розділи) → уроки розділу. Стан `nav = {v: home|subject|topic, id, sec}`.
- **Плеєр уроку**: `renderScreen()` будує екран за типом, `check()` оцінює, `setDock()` показує фідбек у нижній панелі.
- **Кольори предметів**: `subjectCSS()` генерує CSS-змінні з `colors` у контенті; під час уроку `data-subject` на `<html>` перемикає акцент.
- **Ілюстрації**: `svgFig(name)` — іменовані SVG (історія); `mathFig(spec)` — параметричні фігури (математика).

## Стан користувача
`localStorage["slid.v1"]` (у try/catch; без нього застосунок працює, але не пам'ятає):
```
{ name, grade, theme, subject, unlockAll, weekOverride,
  xp, lessons: {id: {done, stars, best}}, days: {"2026-09-27": xp},
  streak: {count, last}, badges: {id: date}, skills: {"math.frac": {ok, total}}, polls: {key: index}, bestCombo,
  diag: {dg6: {done, date, res, topics}}, diagRun: {dg6: {i: 1|0|-1}}, diagSkip: {dg6: true},        // тест рівня
  plan: {math: {diag, date, topics, steps: [{l, why, src, done}], known: [lessonId]}},                // персональний план
  mast: {lessonId: {r: "0110", d}}, skw: {"math.cmp": "1011"}, errs: [{l, at, sk, d}] }               // останні відповіді тем і навичок, журнал помилок
```
id уроків і навичок — ключі в прогресі. **Не перейменовуйте їх** після публікації.

## Гейміфікація
- Бали: 10 з першої спроби, 5 з другої, +5 за серію 3/5/7…, +20 за урок, +10 без помилок; фінальні уроки ×2.
- Зірки: ≥ 90 % з першої спроби — 3, ≥ 65 % — 2, інакше 1.
- Рівні: 8 порогів (Новачок → Легенда). Серія днів, денна ціль 40 балів.
- Значки: загальні (у рушії) + предметні (`subject.badges`) + розділові (`sec.badges`).
- Навмисно **немає «життів»**, які забирають за помилки: для дітей у стресових умовах покарання шкодить.

## Клас і «Зараз у школі»
Клас обирають при першому запуску. Показуються лише розділи цього класу. Тиждень навчального року рахується від понеділка тижня з 1 вересня (можна змінити в профілі для тестування). Розділи з `weeks`, що містять поточний тиждень, — у картці «Зараз у школі».

## Передумови між класами
`sec.requires` — чип на екрані розділу. `screen.pre` — якщо дитина помиляється, у фідбеку з'являється підказка, а наприкінці уроку — картка «Варто повторити» з кнопкою запуску уроку іншого класу.

## Персоналізація
Тест рівня після вибору класу, персональний план і пошук повторюваних помилок — docs/PERSONALIZATION.md. Логіка в `app/learn.js` (без DOM, тести `tools/test-learn.mjs`); id тестів і тем — теж ключі в прогресі.
