# Схема контенту

Увесь навчальний зміст — JavaScript-файли в `content/`, які викликають функції реєстру з `app/registry.js`.
Нічого не треба компілювати: браузер підвантажує файли по черзі (список у `index.html` оновлює `tools/build.mjs`).

## 1. Предмет — `content/subjects/<id>.js`

```js
SLID.subject({
  id: "hist", subject: "Історія України", short: "Історія", icon: "pot", pattern: "spiral",   // pattern: spiral | grid | none
  colors: { light: { accent: "#A8431F", soft: "#F3E3DA", mid: "#D98E6E", ink: "#FFFFFF" },
            dark:  { accent: "#E0764E", soft: "#3A2419", mid: "#8A4A33", ink: "#1A1310" } },
  skills: { src: { name: "Джерела", hint: "Розрізняти види джерел…" } },   // навички для екрана «Прогрес»
  badges: [ { id: "hstar", name: "Зіркова історія", icon: "star", desc: "…", allstar: true } ]
});
```
Кольори генерують CSS автоматично. `allstar: true` — значок за 3 зірки в усіх уроках предмета в поточному класі.

## 2. Розділ — `content/<предмет>/g<клас>-<id>.js`

```js
SLID.section("math", {
  id: "ms1",               // унікальний на весь застосунок; для розділу з плану — той самий id, що в plan.js
  grade: 5,                // клас; від нього залежить фільтр у застосунку
  weeks: [16, 21],         // тижні навчального року (1–35) для картки «Зараз у школі»
  title: "Звичайні дроби",
  why: "Щоб чесно ділити піцу…",       // «Навіщо» — показується дитині
  requires: ["m4a"],       // необов'язково: уроки-передумови (чип «Спирається на»)
  signed: true,            // необов'язково: кнопка «±» в усіх числових полях розділу (з 7 класу вона є завжди) — щоб її поява не видавала знак відповіді
  plan: ["…"],             // необов'язково: переходить із plan.js автоматично
  meta: { author: "claude-opus", created: "2026-09-27", factcheck: "self", teacher: null },
  badges: [ { id: "mboss", name: "Кондитер", icon: "trophy", desc: "…" } ],   // значки, що видаються уроками розділу
  credits: [ ["Назва фото", "Автор", "Ліцензія", "https://commons.wikimedia.org/wiki/File:…"] ],
  lessons: [ /* уроки */ ]
});
```
Розділ **без** `lessons` — плановий (лише в `plan.js`): показується з темами й позначкою «уроки готуються».

  screens: [ /* екрани */ ],

## 4. Екрани

Спільні поля: `type`, `eyebrow` (надзаголовок), `title`, `body` (HTML), `sk` (ключ навички), ілюстрація — одне з:
`img` + `cap` (+ `tall` для вертикальних фото на чорному тлі або `fit` на білому), `svg` (назва SVG-ілюстрації з `svgFig()` в app.js), `fig` (математична фігура, див. §6),
`lab` (інтерактивна модель, див. §8 — можна й на `choice`/`number`: дитина експериментує, перш ніж відповісти).

Примітка під текстом екрана (будь-який тип) — `note`: згорнутий рядок «Чому дві дати?», що розгортається по натиску (D-022). Рядок HTML або `{ text, label?, links? }`; `label` — інший заголовок замість «Чому дві дати?», `links` — `[["Назва джерела", "https://…"], …]`. Примітка не оцінюється й не може бути опорою для завдання — лише пояснення, чому джерела розходяться.
```js
note: { text: "<p>Літопис називає 945 р., але …</p>", links: [["Ігор — Енциклопедія історії України", "https://…"]] }
```

Для завдань: `fbOk` (заголовок при правильній), `fbBad` (заголовок при помилці), `fbText` (пояснення **чому** — показується завжди), `hint` (підказка після першої помилки), `pre` (id уроку-передумови: при помилці дитині запропонують його повторити).

Механіка завдань: перша помилка → підказка й друга спроба; друга помилка → показ правильної відповіді. 10 балів з першої спроби, 5 з другої; серія з 3, 5, 7… правильних — бонус.

| type | Поля | Що робить дитина |
|---|---|---|
| `intro` | `cta` | читає проблему, з якої починається урок |
| `info` | `cta` | читає теорію (після проблеми!) |
| `choice` | `opts[]`, `correct` (індекс) | обирає один варіант |
| `choice` + `poll: "key"` | `opts`, `fbTitle`, `fbText` | опитування без правильної відповіді; вибір згадується в `outro` |
| `choice` + `hyp: true` | `opts`, `fbTitle`, `fbText` | висуває гіпотезу; усі відповіді приймаються |
| `multi` | `opts[]`, `correct[]` | обирає кілька |
| `sort` | `bins[]`, `items: [[текст, індекс кошика], …]` | розкладає по кошиках |
| `order` | `items[]` (у правильному порядку), `shuffle[]` (порядок показу — перестановка індексів) | торкається в правильній послідовності |
| `slider` | `min`, `max`, `step`, `start`, `answer`, `tol` (частка), `unit` | оцінює число; зараховується в межах ±tol |
| `align` | `ref: {from, to, seed}`, `sample: {len, endYear}` | суміщає візерунок кілець дерева з еталоном |
| `shade` | `shape: "bar"|"circle"`, `n`, `target` | зафарбовує частини фігури |
| `numline` | `den`, `max`, `answer` (у поділках) | ставить точку на координатному промені |
| `number` | `answer` (число), `unit`, `tol` (допустима похибка, необов'язково), `signed` | вводить число; поле завжди приймає кому; якщо `answer` від'ємне (або `signed: true`) — з'являється кнопка «±» |
| `explore` | `lab` | досліджує інтерактивну модель (без оцінки), див. §8 |
| `lab` | `lab`, `goal`, `solution`, `reveal` | змінює модель, щоб виконати умову `goal`; оцінюється, див. §8 |
| `fracin` | `expr`, `den`, `answer` | вписує чисельник у дріб: `expr = ?/den` |

Приклад завдання:
```js
{ type: "choice", sk: "cmp", eyebrow: "Порівняй", title: "$3/8$ … $3/5$",
  body: "<p>Який знак поставити?</p>", opts: ["&lt;", "&gt;", "="], correct: 0,
  hint: "Чисельники однакові. Де шматки більші?",
  fbOk: "Молодець.", fbBad: "Згадай правило 2.",
  fbText: "Чисельники однакові, але восьмі частини менші за п'яті. Отже, $3/8 < 3/5$." }
```

## 5. Формули

У будь-якому тексті: `$…$` — у рядку, `$$…$$` — окремим рядком по центру. Усередині:

| Пишеш | Бачить дитина |
|---|---|
| `3/4` | дріб стовпчиком |
| `2~3/4` | мішане число 2¾ |
| `(a + b)/c` | чисельник з кількох знаків |
| `*` | множення · |
| `:` | ділення : (як у школі, а не ÷ чи /) |
| `-` | мінус − |
| `a`, `x` | змінні курсивом |
| `"(ост. 2)"` | звичайний текст усередині формули |
| `x^2`, `(x-1)^2`, `2^(n-1)` | степінь (верхній індекс) |

⚠️ У рядках у зворотних лапках (`` `…` ``) не пиши `${` — JavaScript сприйме це як вставку. `$1/5$` безпечно, а от `$${`… — ні. Валідатор це ловить.

## 8. Лабораторія: інтерактивні моделі (`lab`)

Як у Brilliant: дитина **тягне повзунки або точки** й одразу бачить, як змінюється графік, фігура, числова пряма чи терези.
Рушій — `app/lab.js`; валідатор сам перевіряє вирази, мету й розв'язок.

Три способи використати:
- `type: "explore"` — модель для дослідження без оцінки («Пограйся з k. Що відбувається з прямою?»). Далі — `choice` з висновком.
- `type: "lab"` — завдання: «Зроби так, щоб…». Поля `goal` (умова-вираз), `solution` (значення параметрів, що її виконують — для показу відповіді й плейтесту), `reveal` (необов'язково: текст під моделлю, коли показано відповідь).
- `lab` на звичайному завданні (`choice`, `number`) — модель як жива ілюстрація до питання.

### 8.1. Параметри, вирази, шаблони
```js
lab: { kind: "plane",
  params: { k: { min: -3, max: 3, step: 0.5, start: 1, label: "$k$" }, b: { min: -4, max: 4, start: 0 } },  // повзунки; step за замовчуванням 1
  // межі можуть залежати від інших параметрів: k: { min: 0, max: "n", start: 1 } — не більше, ніж частин
  // out: false — не показувати число біля повзунка (коли дитина має прочитати шкалу сама); values: false — для всіх повзунків моделі
  let: { s: "k*2+b" },                       // похідні величини (необов'язково)
  fns: [{ id: "f", y: "k*x+b" }],            // функції від x; з id їх можна викликати: f(2)
  points: { M: { x: "2", y: "f(2)" }, P: { at: [1, 1], drag: true } },
  show: "$y = {k; b|poly}$"                  // рядок(и) під моделлю з живими значеннями
}
```
- **Вирази** — рядки: `+ - * / ^`, дужки, неявне множення (`2x`, `3(x+1)`), порівняння `== != < > <= >=`, `&& || !`. Десятковий знак у виразах — **крапка** (`0.5`); дитина бачить кому.
  Функції: `sqrt abs sin cos tan` (радіани), `sind cosd tand` (градуси), `ln lg log(b,x) exp root(n,x) min max round(x,d) floor ceil mod fact C(n,k) A(n,k)`,
  геометрія `dist(A,B) angle(A,B,C)` (градуси, кут при B) `area(A,B,C,…) slope(A,B) X(P) Y(P) pt(x,y)`, аналіз `d(f,a)` (похідна), `integ(f,a,b)`, `mean(…)`. Сталі `pi`, `e`.
  `==` порівнює з допуском 10⁻⁶. Ім'я `x` у `plane` зарезервоване. Кілька літер поспіль — одне ім'я (`kx` ≠ `k*x`).
- **Шаблони** (`show`, `label` тощо): `{вираз}` — число (до 2 знаків), `{вираз|0}` — ціле, `{вираз|c}` — коефіцієнт (1 → «», −1 → «−»),
  `{вираз|s}` — доданок зі знаком («+ 3», «− 2», 0 → «»), `{вираз|deg}` — градуси, `{вираз|pi}` — частки π, `{год|time}` — «14:30», `{хв|hm}` — «2 год 15 хв», `{a; b; c|poly}` — многочлен `ax² + bx + c` з правильними знаками.
  ⚠️ Шаблони пиши у звичайних лапках `"…"`, не у зворотних (`` `${k}` `` JavaScript «з'їсть»).
- **Перетягування:** точка з `drag: true` і `x`/`y`, що є іменами параметрів, рухає ці параметри (`{ x: "a", y: "f(a)", drag: true }` — точка ковзає графіком).
  Скорочення `{ at: [5, 4], drag: true }` створює приховані параметри `Ax`, `Ay` (крок `snap` моделі або `step` точки, за замовчуванням 1). У `solution` вказуй саме їх: `{ Ax: 1, Ay: 5 }`.
- **Мета** `goal` — вираз, що стає істинним, коли завдання виконано: `"f(2)==3"`, `"angle(B,O,A)==90"`, `"a*b==12 && a!=b"`. Валідатор перевіряє: на старті мета **не** виконана, `solution` досяжне повзунками й виконує мету.
  Якщо правильних відповідей кілька — пиши умову, а не конкретні значення (`"a*b==12"`, а не `"a==4 && b==3"`).

### 8.2. Види моделей (`kind`)
| kind | Ключові поля | Для чого |
|---|---|---|
| `plane` | `view: [x0,x1,y0,y1]`, `grid` (крок сітки; `[крок по x, крок по y]`, якщо осі в різних одиницях: кілограми й гривні), `h` (висота поля в px для різних масштабів осей), `xstep`/`ystep`, `xpi: true` (підписи в π), `fns: [{y, id, color, dash, label, from, to}]` або `{x: "c"}` (вертикальна пряма), `fills: [{y, y2 \| "top" \| "bottom", from, to}]`, `points`, `segs: [["A","B"] або {a, b, arrow, label, dash}]`, `lines: [{through: ["A","B"]}]`, `polys: [{pts: [...]}]`, `circles: [{c, r}]`, `angles: [{from, at, to}]`, `texts: [{at, t}]` | координатна площина, графіки з параметрами, перетворення графіків, системи (точка перетину), нерівності (заливка), геометрія з перетягуванням (кути, трикутники, паралельні, коло), вектори, дотична, площа під графіком, одиничне коло |
| `numline` | `view: [a,b]`, `tick`, `labels`, `fmt` (формат підписів осі, як у шаблонах: `"time"` → 15:00, `"hm"`, `"0"`), `points` (`hollow` — виколота), `jumps: [{from, to, label}]` або `{from, by, repeat: "n"}` (n однакових стрибків), `intervals: [{from, to, open: [bool,bool]}]` (`null` — до нескінченності) | цілі й раціональні числа, додавання як «стрибки», модуль, десяткові дроби, проміжки й нерівності |
| `rect` | `a`, `b` (вирази, зазвичай параметри), `max: [ширина, висота]` (масштаб), `split` (розріз по ширині), `splitY` (по висоті), `splitLabels`/`splitYLabels: ["шаблон", "шаблон"]` (власні підписи двох частин, напр. дробами), `cells`, `unit` | площа й периметр, таблиця множення, розподільна властивість, $(a+b)^2$ |
| `column` | `op: "+" \| "-" \| "*" \| ":"` (`:` — ділення куточком з неповними діленими й остачею; `step` — скільки цифр частки відкрито), `a`, `b`, `step` (параметр: скільки розрядів результату відкрито; для множення на багатоцифрове — скільки неповних добутків) | додавання, віднімання (позика — крапка над розрядом), множення в стовпчик з переносами. **Оцінюване:** `input: true` — дитина торкається клітинок результату й вписує цифри (параметри `d0` — одиниці, `d1`, …; «?» = ще не вписано), мета `goal: "col==734"`, `solution: { d0: 4, d1: 3, d2: 7 }`; `carries: true` — показувати переноси як підказку |
| `fraction` | `items: [{shape: "bar" \| "circle" \| "grid", n, k, label}]` (`grid` — сотка для відсотків) | дроби, рівні дроби, порівняння, відсотки |
| `chart` | `bars: [{label, v}]`, `max`, `mean: true`, `pie: true`, `legend: "pct" \| "value" \| "label"` (що писати в легенді кругової; `"label"` — щоб не підказувати відсотки) | діаграми, середнє значення |
| `balance` | `left`/`right: [["x", "3"], ["1", "2"]]` (3 коробки x і 2 гирі), `x` (вага коробки — параметр) | рівняння як терези: «що зробити з обома шальками» |
| `solid` | `shape: "box" \| "prism" \| "pyramid"`, `a, b, c` (box) або `n, r, h`, `cubes: true` (сітка одиничних кубиків), `marks` | паралелепіпед, об'єм кубиками, призма, піраміда; обертається пальцем |

Кольори: `accent` (колір предмета), `blue`, `green`, `red`, `gold`, `purple`, `muted`, `ink`.

### 8.3. Приклад завдання
```js
{ type: "lab", sk: "func", eyebrow: "Спробуй", title: "Проведи пряму через точку M",
  body: "<p>Змінюй $k$ і $b$, доки пряма не пройде через $M(2; 3)$.</p>",
  lab: { kind: "plane", params: { k: { min: -3, max: 3, step: 0.5, start: 0 }, b: { min: -4, max: 4, start: 0 } },
         fns: [{ id: "f", y: "k*x+b" }], points: { M: { x: "2", y: "3", color: "red", coords: true } }, show: "$y = {k; b|poly}$" },
  goal: "f(2)==3", solution: { k: 1, b: 1 },
  hint: "Підстав $x = 2$: має вийти $2k + b = 3$.",
  fbOk: "Пряма проходить через M.", fbText: "Точка лежить на графіку, якщо її координати задовольняють рівняння: $2k + b = 3$. Підходить, наприклад, $k = 1$, $b = 1$ або $k = 2$, $b = -1$." }
```
