# Зображення

## Правила
- Лише **відкриті ліцензії**: суспільне надбання, CC0, CC BY, CC BY-SA. Головне джерело — Вікісховище (commons.wikimedia.org).
- Кожне фото в уроці має `cap` (що, де, коли; для репродукцій — автор і дата) і запис у `credits` розділу: `[назва, автор, ліцензія, URL сторінки файлу]`. Авторство показується в «Профіль → Джерела зображень».
- Не використовуйте фото, на яких головне — впізнавані приватні особи, крім публічних подій і історичних постатей.
- Сучасні скульптури й будівлі: в Україні немає «свободи панорами», тому фото сучасних пам'ятників (автор живий або помер < 70 років тому) краще не брати.
- Формат: JPEG, ширина ≤ 1000 px, якість ~0,75–0,8, ≤ 250 КБ. Вертикальні фото — прапорець `tall` (чорне тло) або `fit` (біле тло, для гербів і схем).
- Теки: `img/<предмет>/<id розділу>/<назва>.jpg` для нових розділів. Старі файли першої сесії лежать просто в `img/`.
- **Історія (D-027): у кожному уроці — щонайменше одне справжнє зображення `img`** (фото пам'ятки чи предмета, репродукція, документ, історична карта, портрет) з відкритою ліцензією. Схеми `svg`/`fig` можна додавати, але вимогу вони не закривають. Зображення працює на зміст: джерело для завдання або проблема intro, не декор. Чутливі теми — документи, місця пам'яті, портрети, плакати; без натуралістичних фото жертв. validate попереджає про урок без `img`.
- В інших предметах: якщо фото немає, краще намалювати схему (SVG у `svgFig()` або `fig` для математики), ніж узяти випадкову картинку.

## Як завантажити (технічно)
Сторінка-артефакт не показує зображення з чужих доменів (CSP). Тому зображення завжди **лежать поруч із застосунком** і публікуються разом із ним.
- **Локально (Claude Code на вашому комп'ютері):** `curl -L -o img/... "https://upload.wikimedia.org/..."`, потім зменшити (`sips -Z 1000` на macOS або Python Pillow).
- **З хмарної сесії Claude**, де мережа не пускає на wikimedia: відкрити `upload.wikimedia.org/<файл>` у вбудованому браузері, через JS намалювати в canvas, зменшити й завантажити як файл у «Завантаження», потім перенести в проєкт. Так зроблено в першій сесії; подробиці в memory/long/pitfalls.md.

## Приватність під час завантаження
- У запитах до Вікісховища та будь-яких сайтів **не передавай персональних даних**: жодних email, імен чи акаунтів у `User-Agent`, параметрах чи тілі запиту.
  Використовуй нейтральний заголовок, наприклад `-A "SlidEduBot/0.1 (offline lessons project)"`.

## Пошук на Вікісховищі
API: `https://commons.wikimedia.org/w/api.php?action=query&generator=search&gsrsearch=<запит>&gsrnamespace=6&prop=imageinfo&iiprop=url|extmetadata&iiextmetadatafilter=LicenseShortName|Artist&format=json`
Ліцензію й автора беріть з `extmetadata`, а не вгадуйте.
